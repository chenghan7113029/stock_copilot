## 填写规则（正文写完后删掉本节）

1. **先结论后细节**：§2 必须在最前，且结论里出现具体 REF-ID 与 Requirement，禁止"参考了行业最佳实践"。
2. **REF-ID 稳定**：`REF-<topic>-<NN>` 一旦写入就不再复用；废除条目写"作废"并保留行，不删。
3. **每个 REF 都要有 landed 位置**：只作背景的参考放进 §2「不落地的参考」，不要占 §4 的行。
4. **入库有上限**：1–3 个；clone 一律 `--depth 1`，单仓 >50MB 只存摘要 + 链接。
5. **`ref/` 不进 git**：所以本文件是唯一凭据；本文件里没有的 REF 视为没调研过。
6. **无参考也要交**：没有可借鉴的实现时，写 §2「无可借鉴」+ §5 排除理由，proposal 里写"本波无外部参考"。
