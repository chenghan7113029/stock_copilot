# 锚定防御呈现护栏

## 目标

对容易形成心理锚点的绝对价格字段，建立可复用的呈现护栏：默认不展示、用户显式请求才展示、展示时固定提示其局限性。

## V1 模式

`report value` 将现价在多方法公允价区间中的 `price_percentile` 先映射为五档定性描述，再以括号弱化原始分位数；JSON 保留原始数值，供程序化使用。

本地 K 线可推导的历史最高价遵守以下三段式规则：

1. 默认文本报告不计算、不展示该价格；
2. 用户显式传入 `--show-anchor-price` 时，才从本地 `KlineRepo` 读取已缓存记录计算；
3. 输出同时声明缓存记录条数，并附「仅供参考，不建议作为决策心理锚点」警示。

该计算严格离线；缓存不足时不把可得窗口伪称为完整上市历史。

## 复用约束

未来引入成本价、持仓盈亏或其他绝对价格锚点时，应复用「默认隐藏 + 显式 opt-in + 固定警示」模式。`add-fresh-entry-check` 可在无仓位视角中进一步决定成本价的具体交互，但不得恢复为默认展示。
