## 1. MA（移动平均线）

### 适用场景

MA 是所有技术分析的**基础层**，适用于一切 A 股标的。通过均线排列判断趋势方向，通过均线支撑识别介入点，通过均线间距变化判断趋势强弱。MA 在趋势明显的品种中效果显著，在无趋势的横盘振荡行情中频繁假信号。

### 方法描述

简单移动平均（SMA）对 N 个收盘价等权重求平均，是趋势判断的「基准线」。系统计算 4 条均线构成支撑/压力体系：

- **MA5（5日线）**：最灵敏，代表短期趋势，回踩 MA5 为最佳短线买点；
- **MA10（10日线）**：中短期趋势，趋势行情中为最佳回踩支撑；
- **MA20（20日线）**：月线，长期趋势方向基准，破位则警惕趋势转弱；
- **MA60（60日线）**：季线，主力成本线，大级别支撑/压力位。

### 计算公式

$$\text{MA}_N(t) = \frac{1}{N} \sum_{i=0}^{N-1} C_{t-i}$$

其中 $C_t$ 为第 $t$ 日收盘价，$N$ 为均线周期。

**数据不足时的处理**：当历史数据不足 60 天时，MA60 用 MA20 代替，并在 `risk_factors` 中注明"MA60 数据不足，以 MA20 替代"。

### 因子含义

| 变量 | 含义 | 注意事项 |
|------|------|---------|
| MA5 | 近 5 日平均成本 | 短线操作的主要参考线，盘中往往也构成重要支撑 |
| MA10 | 近 10 日平均成本 | 趋势中段介入的主要参考，月内操作者重点关注 |
| MA20 | 近 20 日平均成本 | 「月线」，中期多空分界线；跌破视为趋势可能转弱 |
| MA60 | 近 60 日平均成本 | 主力机构成本线，大趋势参考；数据不足时以 MA20 替代 |
| `ma_alignment` | 均线排列描述文字 | 程序生成的人读描述，如「强势多头排列，均线发散上行」 |
| `trend_strength` | 趋势强度 0~100 | 基于均线间距变化计算，强势多头：90，空头：10~25 |

### 配置参数与默认值

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `ma_periods` | [5, 10, 20, 60] | 可自行增减周期 |

### 方法局限性

- **滞后性**：均线是历史均值，信号确认时价格已移动一段，在快速拉升/急跌时跟不上；
- **横盘失效**：无趋势行情中均线频繁交叉，信号噪声大；
- **参数敏感性**：不同周期参数对信号影响较大，同一股票不同周期结论可能矛盾；
- **不考虑成交量**：纯价格均线无法区分有量突破和无量涨跌，需配合量能分析。

### 案例 A：看多——贵州茅台（600519）多头排列买点

**假设数据**：
- 当前价 = 1680.00 元
- MA5 = 1661.20 元，MA10 = 1648.50 元，MA20 = 1630.00 元，MA60 = 1590.00 元

**分析**：
```
均线排列：MA5 > MA10 > MA20 > MA60 ——  标准多头排列
均线发散：(MA5 - MA20) / MA20 = 1.9%（较前一周期 1.5% 扩大）→ 强势多头
乖离率 (vs MA5)：(1680 - 1661) / 1661 = +1.14%  → 贴近 MA5，未追高
```
**信号**：多头排列且价格贴近 MA5，符合「回踩支撑」特征，是理想介入时机。

### 案例 B：看空——空头排列需规避

**假设数据**：
- 当前价 = 45.00 元
- MA5 = 46.20 元，MA10 = 48.00 元，MA20 = 51.00 元

**分析**：
```
均线排列：MA5 < MA10 < MA20 ——  空头排列（价格位于所有均线下方）
（MA20 - MA5）/ MA5 = 13.3% → 间距仍在扩大 → 强势空头
```
**信号**：价格低于所有均线且空头发散，无论估值多便宜，均不宜介入；止损位可参考 MA10（48 元）。

## 2. 乖离率（BIAS）

### 适用场景

乖离率是技术面「**不追高**」策略的核心过滤器。当股价相对均线的偏离度过大时，均值回归风险显著上升。主要用于阻止在趋势行情中追涨导致买在阶段高点。

### 方法描述

乖离率衡量当前价格偏离某条均线的幅度，正值代表价格高于均线（高于均值）；负值代表价格低于均线（可能超卖或回调机会）。

系统以 **BIAS(MA5)** 作为主要判断依据，同时计算 BIAS(MA10) 和 BIAS(MA20) 作为参考。

### 计算公式

$$\text{BIAS}_{MA_N}(t) = \frac{C_t - \text{MA}_N(t)}{\text{MA}_N(t)} \times 100\%$$

### 因子含义

| 变量 | 含义 | 注意事项 |
|------|------|---------|
| `bias_ma5` | 价格相对 MA5 的偏离百分比 | 主要评分依据；正值=高于均线（追高风险），负值=低于均线（回调） |
| `bias_ma10` | 价格相对 MA10 的偏离百分比 | 中期参考；-5% 附近常为较好的中线介入位 |
| `bias_ma20` | 价格相对 MA20 的偏离百分比 | 大幅偏离 MA20（如 >15%）时，中期回调风险极高 |
| `bias_threshold` | 配置项，默认 5.0% | 超过此值判定为「追高」，强制低评分 |

### 配置参数与默认值

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `bias_threshold` | 5.0% | 超过此值：评分仅 4 分（20 满分），并加入风险提示「严禁追高！」 |
| `strong_trend_bias_multiplier` | 1.5 | 强势趋势（STRONG_BULL + 趋势强度≥70）时，有效阈值放宽至 7.5% |

### 评分规则（bias_weight = 20 分满分）

| bias_ma5 区间 | 得分 | 描述 |
|---------------|------|------|
| < -5% | 8 | 大幅低于 MA5，可能已破位，需结合趋势判断 |
| -5% ~ -3% | 16 | 回踩 MA5，观察支撑 |
| -3% ~ 0% | 20 | 价格略低于 MA5，回踩买点（最优） |
| 0% ~ +2% | 18 | 价格贴近 MA5，好时机 |
| +2% ~ +threshold | 14 | 略高于 MA5，可小仓介入 |
| > +threshold（普通） | 4 | 追高！严禁全仓介入 |
| +threshold ~ +1.5×threshold（强势趋势） | 10 | 强势趋势中偏高，可轻仓跟踪 |

### 方法局限性

- **不适用横盘股**：无趋势的股票乖离率频繁来回波动，不构成有效信号；
- **均值回归不确定时间**：高乖离率可能持续较长时间（特别是强趋势行情）；
- **单独使用易被套**：乖离率过高不一定立即回调，需配合 MACD/RSI 进行顶部确认。

### 案例 A：乖离率适中——安全介入

**数据**：当前价 = 30.50，MA5 = 30.10，BIAS(MA5) = +1.33%

**结论**：价格贴近 MA5 且正乖离在阈值内，评分 18/20，介入风险低。

### 案例 B：乖离率过高——回避追高

**数据**：当前价 = 35.20，MA5 = 29.80，BIAS(MA5) = +18.1%

**结论**：超过阈值的 3 倍以上，极度追高状态，评分 4/20，风险提示「严禁追高！」。即便趋势良好，综合评分也将被这一项大幅拖累。

## 3. 均线支撑/压力位

### 适用场景

支撑位识别用于确认「**回踩均线且获得支撑**」的买点特征，是评分体系中的加分项。压力位识别用于辅助设定止盈参考。

### 方法描述

系统在以下场景中判定均线为有效支撑：
1. 当前价 ≥ 均线值（价格在均线上方）；
2. 当前价与均线的距离 ≤ 容忍度（2%）；
3. MA5 支撑和 MA10 支撑分别独立判断。

压力位取近 20 日最高价中高于当前价的部分。

### 计算公式

$$\text{support\_valid} = \left|\frac{C_t - \text{MA}_N}{\text{MA}_N}\right| \leq \varepsilon \quad \text{且} \quad C_t \geq \text{MA}_N$$

其中 $\varepsilon$ = `ma_support_tolerance`（默认 2%）。

### 因子含义

| 变量 | 含义 |
|------|------|
| `support_ma5` | MA5 是否构成有效支撑（bool） |
| `support_ma10` | MA10 是否构成有效支撑（bool） |
| `support_levels` | 所有有效支撑价格列表（MA5/MA10/MA20 的当前值） |
| `resistance_levels` | 压力价格列表（近 20 日高点中高于当前价的部分） |

### 评分规则（support_weight = 10 分满分）

- MA5 支撑：+5 分
- MA10 支撑：+5 分（两者可同时满足，最高 10 分）

### 方法局限性

- **支撑可被假突破**：主力有时刻意下探均线下方吸筹后快速拉起，肉眼看破位实际是洗盘；
- **历史高点压力可被突破**：放量突破近期高点后，原来的压力变为支撑；
- **2% 容忍度较窄**：高波动股票可能惯常超出 2% 后反弹，判断支撑时应结合个股波动特征。

## 4. 趋势状态评估

### 适用场景

趋势状态评估是整个评分体系的**最高权重维度（30 分）**，是「顺势而为」交易哲学的核心体现。在非多头趋势下，哪怕所有其他信号优秀，系统也会在 `buy_signal` 层面降级或阻止买入。

### 方法描述

通过比较 MA5、MA10、MA20 三条均线的大小关系，以及均线间距的动态变化（趋势是否在加速/减速），将趋势分为 7 个状态。

### 判断逻辑

```
输入：ma5, ma10, ma20，以及前 5 日的 ma5_prev, ma20_prev

判断顺序：
1. MA5 > MA10 > MA20？
   - 当前扩散度 curr_spread = (MA5 - MA20) / MA20 * 100
   - 前期扩散度 prev_spread = (MA5_prev - MA20_prev) / MA20_prev * 100
   - 若 curr_spread > prev_spread AND curr_spread > 5% → STRONG_BULL（强势多头，均线发散上行）
   - 否则 → BULL（多头排列）

2. MA5 > MA10 且 MA10 ≤ MA20？
   → WEAK_BULL（弱势多头，MA5 领先但 MA10 尚未上穿 MA20）

3. MA5 < MA10 < MA20？
   - 若空头扩散度 curr > prev AND curr > 5% → STRONG_BEAR（强势空头，均线发散下行）
   - 否则 → BEAR（空头排列）

4. MA5 < MA10 且 MA10 ≥ MA20？
   → WEAK_BEAR（弱势空头，MA5 领跌但 MA10 尚未跌破 MA20）

5. 其他（均线缠绕，大小关系不明确）
   → CONSOLIDATION（盘整）
```

### 趋势状态与评分对照

| 趋势状态 | 趋势强度 | 趋势评分 | 描述 |
|---------|---------|---------|------|
| STRONG_BULL | 90 | 30 | 均线发散上行，趋势加速 |
| BULL | 75 | 26 | 标准多头排列 MA5>MA10>MA20 |
| WEAK_BULL | 55 | 18 | MA5>MA10 但 MA10≤MA20，均线交叉中 |
| CONSOLIDATION | 50 | 12 | 均线缠绕，方向不明 |
| WEAK_BEAR | 40 | 8 | MA5<MA10 但 MA10≥MA20 |
| BEAR | 25 | 4 | 标准空头排列 MA5<MA10<MA20 |
| STRONG_BEAR | 10 | 0 | 均线发散下行，趋势加速下跌 |

### 方法局限性

- **均线排列有滞后**：价格已经见底反转，但均线排列可能仍处于 BEAR 状态（因为均线需要多日数据响应）；
- **扩散度 5% 阈值是经验值**：不同行业、不同波动率个股的「正常扩散度」差异较大；
- **不区分趋势时间维度**：MA5/10/20 代表短中期，大级别趋势（月线/季线）需参考 MA60，系统当前未纳入趋势状态判断。

## 5. MACD（指数平滑异同移动平均）

### 适用场景

MACD 是趋势确认与反转预警的核心指标，适用于**趋势性明显的 A 股标的**，是均线趋势判断的动量验证器。「零轴上金叉」是最强买入信号；「死叉」和「零轴下穿」是趋势转弱的重要预警。

### 方法描述

MACD 由三部分组成：
- **DIF（快线）**：快速 EMA（12 日）与慢速 EMA（26 日）之差，代表短期趋势动量；
- **DEA（慢线/信号线）**：DIF 的 9 日 EMA，代表中期趋势方向；
- **MACD 柱（Bar）**：`(DIF - DEA) × 2`，代表买卖双方力量对比。

MACD > 0（红柱）表示多方占优；MACD < 0（绿柱）表示空方占优。柱状图由负转正是金叉，由正转负是死叉。

### 计算公式

$$\text{EMA}_{fast}(t) = \text{EMA}(Close, 12)$$
$$\text{EMA}_{slow}(t) = \text{EMA}(Close, 26)$$
$$\text{DIF}(t) = \text{EMA}_{fast}(t) - \text{EMA}_{slow}(t)$$
$$\text{DEA}(t) = \text{EMA}(\text{DIF}, 9)$$
$$\text{MACD\_Bar}(t) = (\text{DIF}(t) - \text{DEA}(t)) \times 2$$

其中 EMA 使用指数加权平均（`ewm(span=N, adjust=False)`），即 Wilder's EMA 的标准计算方式（与主流 K 线软件一致）。

### 因子含义

| 变量 | 含义 | 注意事项 |
|------|------|---------|
| `macd_dif` | 快慢均线差（DIF） | 正值表示短期均线在长期均线上方（多头动量） |
| `macd_dea` | DIF 的信号线（DEA） | 代表 DIF 的趋势方向，比 DIF 滞后一些 |
| `macd_bar` | 柱状图 `(DIF-DEA)×2` | 正红柱：多方占优且扩张；负绿柱：空方占优 |
| `macd_status` | MACD 状态枚举（7级） | 程序判断的最终状态，见下表 |
| `macd_signal` | 信号描述文字 | 供 LLM 报告和人工阅读使用 |

### MACD 状态说明

| 状态 | 触发条件 | 含义 |
|------|---------|------|
| `GOLDEN_CROSS_ZERO` | DIF 上穿 DEA 且 DIF > 0 | **最强买入信号**：趋势反转在零轴上方确认 |
| `GOLDEN_CROSS` | DIF 上穿 DEA（零轴以下） | 金叉，趋势向上 |
| `CROSSING_UP` | DIF 从负转正（上穿零轴） | 趋势由弱转强 |
| `BULLISH` | DIF > 0 且 DEA > 0 | 多头区域，延续上涨 |
| `BEARISH` | DIF < 0 且 DEA < 0 | 空头区域，延续下跌 |
| `CROSSING_DOWN` | DIF 从正转负（下穿零轴） | 趋势由强转弱 |
| `DEATH_CROSS` | DIF 下穿 DEA | 死叉，趋势向下 |

### 配置参数与默认值

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `macd_fast` | 12 | 快线 EMA 周期（标准值，勿轻易修改） |
| `macd_slow` | 26 | 慢线 EMA 周期（标准值） |
| `macd_signal` | 9 | 信号线 EMA 周期（标准值） |

### 评分规则（macd_weight = 15 分满分）

| 状态 | 得分 |
|------|------|
| GOLDEN_CROSS_ZERO | 15 |
| GOLDEN_CROSS | 12 |
| CROSSING_UP | 10 |
| BULLISH | 8 |
| BEARISH | 2 |
| CROSSING_DOWN | 0 |
| DEATH_CROSS | 0 |

### 方法局限性

- **滞后性**：MACD 基于 EMA，在价格快速变化时信号有明显延迟；
- **横盘失效**：无趋势市场中 MACD 频繁发出假金叉/死叉，噪声极多；
- **零轴下金叉可能是反弹而非趋势逆转**：需结合趋势状态验证；
- **A 股操盘干扰**：主力可在 MACD 要形成金叉前故意打压价格，诱发个人投资者止损。

### 案例 A：零轴上金叉——最强买入信号

**数据**（某股票连续两日）：

```
昨日：DIF = 0.15，DEA = 0.18  → DIF < DEA（未金叉）
今日：DIF = 0.22，DEA = 0.19  → DIF > DEA（金叉！） 且 DIF > 0（零轴上方）

判断：GOLDEN_CROSS_ZERO
评分：15/15 满分
信号：「零轴上金叉，强烈买入信号！」
```

**解读**：DIF 和 DEA 均在零轴上方，趋势整体多头；DIF 金叉发生在零轴上方，确认趋势继续向上，是最高质量的 MACD 买入信号。

### 案例 B：零轴下死叉——空头确认

**数据**：

```
今日：DIF = -0.35，DEA = -0.28  → DIF < DEA 且 DIF 由 -0.22 跌过 DEA

判断：DEATH_CROSS
评分：0/15 零分
风险提示：「死叉，趋势向下」
```

**解读**：即便均线技术面显示「弱势空头」而非「强势空头」，MACD 死叉已确认短期下行压力，叠加空头趋势则综合评分极低。

## 6. RSI（相对强弱指数）

### 适用场景

RSI 是衡量**价格动量强弱**的经典振荡器，适用于判断超买超卖状态、识别短期反转机会。系统使用三个周期（6/12/24）捕捉短/中/长期动量，以 RSI(12) 作为评分主依据。

RSI 在**趋势性行情中**可以长期处于超买或超卖区域，不宜单独作为反转信号；在**震荡行情**中与均线配合效果更好。

### 方法描述

RSI 衡量一段时间内上涨幅度之和与总振幅的比值，结果归一化到 0~100。系统采用 **Wilder's EMA** 口径（与主流 K 线图软件一致，非简单移动平均口径）。

### 计算公式

$$\Delta_t = C_t - C_{t-1}$$
$$\text{Gain}_t = \max(\Delta_t, 0), \quad \text{Loss}_t = \max(-\Delta_t, 0)$$
$$\overline{\text{Gain}}_t = \text{EWM}(\text{Gain}, \alpha=1/N), \quad \overline{\text{Loss}}_t = \text{EWM}(\text{Loss}, \alpha=1/N)$$
$$\text{RS} = \frac{\overline{\text{Gain}}}{\overline{\text{Loss}}}, \quad \text{RSI} = 100 - \frac{100}{1 + \text{RS}}$$

其中 $\alpha = 1/N$（对应 `ewm(alpha=1/period, adjust=False)`）即 Wilder's Smooth Moving Average，与 `span=2N-1` 的标准 EWM 不同。

### 因子含义

| 变量 | 含义 | 注意事项 |
|------|------|---------|
| `rsi_6` | 6 日 RSI（短期动量） | 最灵敏，对应日内短线操作，容易超买超卖 |
| `rsi_12` | 12 日 RSI（中期动量） | **评分主依据**；代表近半月的多空力量 |
| `rsi_24` | 24 日 RSI（长期动量） | 中长线参考，与 rsi_12 背离时关注趋势变化 |
| `rsi_status` | RSI 状态枚举（5 级） | OVERBOUGHT / STRONG_BUY / NEUTRAL / WEAK / OVERSOLD |

### RSI 状态与阈值

| 状态 | RSI(12) 范围 | 含义 |
|------|------------|------|
| `OVERBOUGHT` | > 70 | 超买：短期回调风险高，谨慎追高 |
| `STRONG_BUY` | 60 ~ 70 | 强势：多方力量充足，可持有或介入 |
| `NEUTRAL` | 40 ~ 60 | 中性：震荡整理，等待方向确认 |
| `WEAK` | 30 ~ 40 | 弱势：空方占优，关注企稳反弹 |
| `OVERSOLD` | < 30 | 超卖：反弹机会大，但需确认见底信号 |

### 配置参数与默认值

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `rsi_short/mid/long` | 6/12/24 | 三档周期，mid 为评分依据 |
| `rsi_overbought` | 70.0 | 超过此值触发超买状态 |
| `rsi_oversold` | 30.0 | 低于此值触发超卖状态 |

### 评分规则（rsi_weight = 6 分，属于动量维度）

| 状态 | RSI 分项得分 |
|------|------------|
| OVERSOLD | 6 |
| STRONG_BUY | 5 |
| NEUTRAL | 3 |
| WEAK | 2 |
| OVERBOUGHT | 0 |

### 方法局限性

- **趋势行情中长期超买/超卖**：强趋势时 RSI 可长期 >70 或 <30，单独使用频繁错误；
- **Wilder's EMA 口径差异**：部分 K 线软件使用不同的 RSI 计算口径（SMA 初始值），可能导致数值略有偏差；
- **三周期背离解读复杂**：短/中/长三档 RSI 背离时需经验判断，程序化处理困难；
- **不反映成交量**：两只涨跌幅相同的股票，RSI 相同，但一个放量一个缩量的意义截然不同。

### 案例 A：RSI 超卖配合均线支撑——高胜率买点

**数据**：
- RSI(6) = 22.5，RSI(12) = 26.3，RSI(24) = 38.1
- 价格刚好回踩 MA10 获得支撑，BIAS(MA5) = -2.1%

**分析**：
```
rsi_status = OVERSOLD（RSI(12) = 26.3 < 30）
RSI 分项得分 = 6（满分）
均线支撑加分 = +5（MA10 支撑有效）
乖离率评分 = 16（回踩 MA5，略低于 MA5）
```
**结论**：RSI 超卖 + 均线支撑有效 = 短线高胜率反弹机会，属于「缩量回踩至超卖区域」的经典买点组合。

### 案例 B：RSI 超买——阶段高位警示

**数据**：RSI(12) = 76.4，当前价格距离 MA5 乖离率 +8.2%（追高状态）

**分析**：
```
rsi_status = OVERBOUGHT，RSI 分项得分 = 0
乖离率得分 = 4（严禁追高）
综合评分被大幅压低
```
**结论**：RSI 超买 + 乖离率过高，是「追高接飞刀」的典型高风险场景，系统强制降级买入信号。

## 7. KDJ（随机指标）

### 适用场景

KDJ 是 A 股最常用的短线振荡指标之一，对超买超卖的**反应比 RSI 更灵敏**，适合捕捉短线转折点。KDJ 金叉（K 上穿 D）是短线买入参考信号；死叉是短线减仓参考信号。J 值超过 100 或低于 0 是极端信号（超买/超卖到极限）。

### 方法描述

KDJ 基于随机指标（Stochastic Oscillator）演化而来：

1. **原始 K 值（RSV）**：过去 N 日（默认 9 日）中，今日收盘价相对于最高/最低价的相对位置；
2. **平滑 K 值**：对 RSV 进行指数平滑（1/smooth_k 权重，默认 1/3）；
3. **D 值**：对 K 值再次平滑；
4. **J 值**：`J = 3K - 2D`（J 放大了 K 与 D 之间的背离，是最灵敏的线）。

J 值理论范围可超出 [0, 100]（特别敏感，超界表示极端状态）。**系统保留 J 值原始值（不 clip）**，在枚举判断层处理超界情况：`J > 100` 叠加 OVERBOUGHT 状态，`J < 0` 叠加 OVERSOLD 状态，并在 `risk_factors` 中注明「KDJ J 值超界：{j:.1f}」供使用者关注。

### 计算公式

$$\text{RSV}(t) = \frac{C_t - \min(Low_{t-N+1}^{t})}{\max(High_{t-N+1}^{t}) - \min(Low_{t-N+1}^{t})} \times 100$$

$$K(t) = K(t-1) \times \frac{smooth\_k - 1}{smooth\_k} + \text{RSV}(t) \times \frac{1}{smooth\_k}$$

$$D(t) = D(t-1) \times \frac{smooth\_d - 1}{smooth\_d} + K(t) \times \frac{1}{smooth\_d}$$

$$J(t) = 3 \times K(t) - 2 \times D(t)$$

**默认参数**：N=9（计算 RSV 的回看周期），smooth_k=3，smooth_d=3。

**初始值处理**：K(0) = D(0) = 50（中性值），标准做法。

### 因子含义

| 变量 | 含义 | 注意事项 |
|------|------|---------|
| `kdj_k` | 平滑 K 值（0~100，但可轻微超界） | 随机指标快线，比 D 更灵敏 |
| `kdj_d` | 平滑 D 值（0~100） | 随机指标慢线（K 的进一步平滑） |
| `kdj_j` | J 值 `= 3K - 2D` | 最灵敏线，**保留原始值不裁剪**；J < 0 极端超卖（叠加 OVERSOLD），J > 100 极端超买（叠加 OVERBOUGHT），同时触发 risk_factors 提示 |
| `kdj_status` | KDJ 状态枚举（5 级） | 见下表 |

### KDJ 状态说明

| 状态 | 触发条件 | 含义 |
|------|---------|------|
| `OVERBOUGHT` | K > 80 且 D > 80 | 超买，警惕短线回调 |
| `GOLDEN_CROSS` | 前 K ≤ 前 D，今 K > D（在超卖区 <30 更有效） | 短线买入信号 |
| `NEUTRAL` | 其他情况（20 < K,D < 80） | 中性区间，无明显信号 |
| `DEATH_CROSS` | 前 K ≥ 前 D，今 K < D（在超买区 >80 更有效） | 短线卖出信号 |
| `OVERSOLD` | K < 20 且 D < 20 | 超卖，关注短线反弹 |

### 配置参数与默认值

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `kdj_period` | 9 | RSV 计算周期（标准值）|
| `kdj_smooth_k` | 3 | K 值平滑系数（1/3 权重） |
| `kdj_smooth_d` | 3 | D 值平滑系数（1/3 权重） |
| `kdj_overbought` | 80.0 | 超买阈值（K 和 D 均超过时触发） |
| `kdj_oversold` | 20.0 | 超卖阈值（K 和 D 均低于时触发） |

### 评分规则（kdj_weight = 4 分，属于动量维度）

| 状态 | KDJ 分项得分 |
|------|------------|
| OVERSOLD | 4 |
| GOLDEN_CROSS | 3 |
| NEUTRAL | 2 |
| DEATH_CROSS | 1 |
| OVERBOUGHT | 0 |

> **总动量维度**：RSI 分项（6分）+ KDJ 分项（4分）= 最高 10 分。

### 方法局限性

- **极度灵敏导致假信号**：KDJ 比 RSI 更早响应，但也更容易在无趋势时频繁发出假金叉/死叉；
- **J 值超界不代表立即转折**：强趋势中 J > 100 可以持续多天，不能单独作为卖出依据；
- **参数标准化问题**：不同软件对 KDJ 初始值（K₀=50 vs K₀=RSV₁）的处理不同，可能导致早期值有偏差；
- **不适合独立决策**：KDJ 最佳使用方式是**配合均线趋势验证**，趋势空头时 KDJ 金叉多为反弹而非反转。

### 案例 A：超卖区金叉——短线高胜率买点

**数据**（连续两日）：
```
昨日：K = 18.3，D = 22.1  → K < D（未金叉）
今日：K = 24.6，D = 22.8  → K > D（金叉！），K 和 D 均在超卖区 (<30) 附近

判断：GOLDEN_CROSS（超卖区附近金叉，效力最强）
KDJ 分项得分：3/4
```

**解读**：超卖区金叉（K 和 D 均在 20~30 之间）是 KDJ 最高质量信号，结合 RSI 超卖状态，短线反弹概率较高。

### 案例 B：超买区——J 值 >100 极端超买

**数据**：K = 88.5，D = 82.3，J = 3×88.5 - 2×82.3 = 101.9

```
判断：OVERBOUGHT（K > 80 且 D > 80）
J 值超过 100，极端超买状态
KDJ 分项得分：0/4
```

**解读**：J > 100 表示短期内买盘力量极度集中，回调风险较高；但若同时处于 STRONG_BULL 趋势，可等待 J 值回落至 80 以下后再寻找介入机会，而非立即止盈。

## 8. 量能分析（Volume Analysis）

### 适用场景

量能分析是趋势真实性的**验证器**，适用于所有 A 股标的。核心原则：**放量 + 上涨 = 健康上涨；缩量 + 回调 = 洗盘特征（好）；放量 + 下跌 = 危险信号**。

技术面「严进」策略对量能偏好明确排序：缩量回调 > 放量上涨 > 量能正常 > 缩量上涨 > 放量下跌。

### 方法描述

计算当日成交量相对于过去 5 日均量的比值（量比），并结合价格涨跌方向判断量能状态。

### 计算公式

$$\text{Vol\_Avg\_5d} = \frac{1}{5} \sum_{i=1}^{5} \text{Vol}_{t-i}$$

$$\text{volume\_ratio\_5d}(t) = \frac{\text{Vol}_t}{\text{Vol\_Avg\_5d}}$$

$$\text{price\_change} = \frac{C_t - C_{t-1}}{C_{t-1}} \times 100\%$$

### 因子含义

| 变量 | 含义 | 注意事项 |
|------|------|---------|
| `volume_ratio_5d` | 当日量 / 5 日均量 | >1.5 为放量，<0.7 为缩量，中间为正常 |
| `volume_status` | 量能状态枚举（5 级） | HEAVY_VOLUME_UP / DOWN / SHRINK_VOLUME_UP / DOWN / NORMAL |
| `volume_trend` | 量能趋势描述文字 | 程序生成，如「缩量回调，洗盘特征明显」 |

### 量能状态判断规则

| 量比（volume_ratio_5d） | 价格涨跌 | 状态 | 描述 |
|------------------------|---------|------|------|
| ≥ 1.5（放量） | 上涨 | `HEAVY_VOLUME_UP` | 放量上涨，多头力量强劲 |
| ≥ 1.5（放量） | 下跌 | `HEAVY_VOLUME_DOWN` | 放量下跌，注意风险（较差信号） |
| ≤ 0.7（缩量） | 下跌 | `SHRINK_VOLUME_DOWN` | 缩量回调，洗盘特征明显（最佳） |
| ≤ 0.7（缩量） | 上涨 | `SHRINK_VOLUME_UP` | 缩量上涨，上攻动能不足 |
| 0.7~1.5（正常） | 任意 | `NORMAL` | 量能正常，无特别信号 |

### 配置参数与默认值

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `volume_shrink_ratio` | 0.7 | 小于此值判定为缩量 |
| `volume_heavy_ratio` | 1.5 | 大于此值判定为放量 |

### 评分规则（volume_weight = 15 分满分）

| 状态 | 得分 |
|------|------|
| SHRINK_VOLUME_DOWN（缩量回调） | 15 |
| HEAVY_VOLUME_UP（放量上涨） | 12 |
| NORMAL（正常） | 10 |
| SHRINK_VOLUME_UP（缩量上涨） | 6 |
| HEAVY_VOLUME_DOWN（放量下跌） | 0 |

### 方法局限性

- **5 日均量容易被主力操控**：在连续放量后的第 6 天，均量基准被推高，当日「正常」量在实际上可能仍是高位量；
- **成交量与流通盘关系**：小盘股的绝对成交量远小于大盘股，量比比绝对量更有意义；
- **换手率更精确**：量比不考虑流通市值，同等量比在不同流通市值股票中意义不同；换手率是更标准化的指标，V1 暂不实现；
- **集合竞价与尾盘成交**：收盘前几分钟的大成交有时是机构被动成交，不代表主动买盘意愿。

### 案例 A：缩量回调——主力洗盘特征

**数据**：
```
5 日均量：8,200,000 手
今日成交量：4,500,000 手
volume_ratio_5d = 4.5 / 8.2 = 0.549（缩量）
今日价格下跌 -1.2%

量能状态：SHRINK_VOLUME_DOWN（缩量回调）
评分：15/15（最高分）
描述：「缩量回调，洗盘特征明显（好）」
```
**解读**：在多头趋势中，价格小幅回调但成交量大幅萎缩，说明卖方力量不强（不是主动砸盘），符合主力洗盘特征；等量能重新放出时，往往是下一段上涨的开始。

### 案例 B：放量下跌——危险信号

**数据**：
```
5 日均量：8,200,000 手
今日成交量：18,600,000 手
volume_ratio_5d = 18.6 / 8.2 = 2.268（显著放量）
今日价格下跌 -3.5%

量能状态：HEAVY_VOLUME_DOWN（放量下跌）
评分：0/15（最低分）
描述：「放量下跌，注意风险」
```
**解读**：大量资金在今日集中卖出，是明确的主动卖出信号，趋势转弱的风险极高；即便当前仍处多头排列，也应高度警惕并设置严格止损。

## 9. 综合评分体系（Signal Scoring）

### 适用场景

综合评分体系将上述 6 个分析维度的结果汇聚为一个 **0~100 分**的单一评分，并映射到 **BuySignal 枚举**（强烈买入 / 买入 / 持有 / 观望 / 卖出 / 强烈卖出）。是技术面分析的**最终决策摘要层**。

### 方法描述

每个维度独立评分，分数之和即为综合评分。`BuySignal` 由评分与趋势状态共同决定（趋势约束优先级高于评分）：

```
评分计算：
  signal_score = trend_score + bias_score + volume_score + support_score + macd_score + momentum_score

  其中 momentum_score = rsi_score（最高 6 分）+ kdj_score（最高 4 分）

BuySignal 判断（趋势约束优先）：
  if 趋势 in {BEAR, STRONG_BEAR}:
      → STRONG_SELL（无视评分）
  elif score >= strong_buy_threshold(75) AND 趋势 in {STRONG_BULL, BULL}:
      → STRONG_BUY
  elif score >= buy_threshold(60) AND 趋势 in {STRONG_BULL, BULL, WEAK_BULL}:
      → BUY
  elif score >= hold_threshold(45):
      → HOLD
  elif score >= wait_threshold(30):
      → WAIT
  else:
      → SELL
```

### 评分汇总表

| 维度 | 满分 | 主要驱动因素 |
|------|------|------------|
| 趋势排列 | 30 | 均线排列状态（7 级）|
| 乖离率 | 20 | 价格偏离 MA5 的程度 |
| 量能 | 15 | 量比 + 价格涨跌方向 |
| 支撑 | 10 | MA5/MA10 支撑有效性 |
| MACD | 15 | MACD 状态（金叉/死叉/零轴） |
| 动量（RSI+KDJ） | 10 | RSI 状态（6分）+ KDJ 状态（4分） |
| **合计** | **100** | |

### 方法局限性

- **权重是经验值，并非统计最优**：当前权重基于 `ref/daily_stock_analysis` 的交易哲学，并非对 A 股历史数据的回测优化结果；
- **维度间相关性高**：多头趋势本身就容易带来 MACD 多头、均线支撑有效等信号，实际上各维度并非完全独立，评分有「叠加放大」效应；
- **不适合作为量化选股排名**：评分面向「单票是否值得介入」，对不同股票的横向排名参考意义有限；
- **强势趋势补偿机制复杂**：乖离率维度在强势趋势时有放宽阈值的特殊逻辑，实际评分行为需读代码才能完全理解。

### 案例 A：理想买点——综合高分

**假设某股数据**：
- 趋势：BULL（26/30）
- 乖离率 BIAS(MA5) = +0.8%，在阈值内（18/20）
- 量能：SHRINK_VOLUME_DOWN（15/15）
- 支撑：MA5 支撑有效（5/10）
- MACD：GOLDEN_CROSS（12/15）
- RSI(12) = 42（中性，RSI 3/6），KDJ NEUTRAL（2/4）

```
综合得分 = 26 + 18 + 15 + 5 + 12 + 3 + 2 = 81 分

BuySignal 判断：
  score(81) >= strong_buy_threshold(75) 且 趋势为 BULL
  → STRONG_BUY（强烈买入）
```

**解读**：多头趋势 + 不追高 + 缩量回调 + 均线支撑 + MACD 金叉，是技术面分析框架中的「教科书级」买点。

### 案例 B：明确回避——空头高分看空

**假设某股数据**：
- 趋势：STRONG_BEAR（0/30）
- 乖离率：BIAS(MA5) = -12%，价格已深跌到 MA5 下方（8/20，但有破位风险）
- 量能：HEAVY_VOLUME_DOWN（0/15）
- 支撑：无均线支撑（0/10）
- MACD：DEATH_CROSS（0/15）
- RSI(12) = 25（超卖，RSI 6/6），KDJ OVERSOLD（4/4）

```
综合得分 = 0 + 8 + 0 + 0 + 0 + 6 + 4 = 18 分

BuySignal 判断：
  趋势为 STRONG_BEAR → 无视评分 → STRONG_SELL（强烈卖出）
```

**解读**：RSI 和 KDJ 都超卖，但这正是「不要在下跌趋势中抄底」的典型场景。趋势空头叠加放量下跌，技术面框架强制给出 STRONG_SELL 信号，与「价值面便宜」无关——这正是双轨分析的价值所在：价值面可以便宜，但技术面未确认见底前不介入。

## 附录：指标间的协同与冲突

### 常见信号组合解读

| 组合 | 含义 | 建议 |
|------|------|------|
| 多头趋势 + MACD 金叉 + RSI < 50 | 趋势延续，动量充足但未超买 | 积极介入 |
| 多头趋势 + MACD 多头 + RSI > 70 | 趋势良好但短期超买 | 等待 RSI 回落后介入 |
| 多头趋势 + 放量下跌 | 趋势可能遭遇考验 | 减仓/止损观察 |
| 盘整 + KDJ 金叉 + 量能正常 | 方向不明，信号弱 | 观望 |
| 空头趋势 + RSI/KDJ 超卖 | 超卖但趋势未反转 | 不抄底，等趋势反转确认 |
| 弱势多头 + MACD 上穿零轴 | 趋势改善迹象 | 轻仓试探，MA20 止损 |

### 指标优先级顺序

```
1. 趋势状态（最高优先级）——空头趋势可否决一切看多信号
2. 乖离率（硬约束）———超过阈值时不追高，即使其他信号好
3. MACD 状态（趋势验证）——金叉/死叉是趋势方向变化的重要确认
4. 量能（可信度验证）———量价配合验证趋势真实性
5. RSI / KDJ（辅助参考）——超买超卖判断，配合其他信号使用
6. 支撑位（精确介入）————细化买点位置，非买不买的决定因素
```
