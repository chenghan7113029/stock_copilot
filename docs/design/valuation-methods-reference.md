## WACC 与折现率参数体系

所有折现类模型（DCF、EPV、DDM、Owner Earnings）共享一套可配置的利率参数体系。

### 基础假设（可配置）

| 参数 | A 股默认值 | 美股/USD 默认值 | 含义 |
|------|-----------|----------------|------|
| `china_10y_yield` | 1.80% | — | 无风险利率（中国 10 年期国债） |
| `us_10y_yield` | — | 4.30% | 无风险利率（美国 10 年期国债） |
| `equity_risk_premium` | 6.00% | 6.00% | 股权风险溢价（ERP） |
| `aaa_corporate_yield` | 5.30% | 5.30% | AAA 级企业债收益率（负债成本 fallback） |
| `tax_rate` | 25% | — | 有效税率（无数据时的 A 股默认） |
| `discount_rate` | 10.0% | 10.0% | 简化场景下的默认折现率 |

### WACC 计算逻辑

```
股权成本（Re）:
    CAPM: Re = Rf + β × ERP
    简化: 直接使用 cost_of_capital 字段（10%）

负债成本（Rd）:
    优先：interest_expense / total_debt（实际利率）
    fallback：aaa_corporate_yield（5.30%）

权重:
    E/V = 市值 / 企业价值（市值 + 净负债）
    D/V = 净负债 / 企业价值

WACC = (E/V) × Re + (D/V) × Rd × (1 - T)
```

### DCF / DDM 默认增长假设

| 参数 | 默认值 | 说明 |
|------|-------|------|
| `growth_rate_1_5` | 5.0% | 第 1-5 年 FCF 增长率 |
| `growth_rate_6_10` | 3.0% | 第 6-10 年 FCF 增长率 |
| `terminal_growth` | 2.0% | 永续增长率（终值） |
| `dividend_growth_rate` | 3.0% | 股息增长率（DDM） |

> **关键约束**：折现率必须严格大于终值增长率（`discount_rate > terminal_growth`），否则模型无解。

## 1. Graham Number（格雷厄姆数）

### 适用场景

适用于**传统制造业、资产密集型蓝筹股**，要求正盈利且账面价值真实反映资产价值。防御型投资者用于快速筛选安全边际充足的股票。

### 方法描述

格雷厄姆在《聪明的投资者》中提出，防御型投资者应同时满足：市盈率（P/E）≤ 15 且市净率（P/B）≤ 1.5，两者乘积不超过 22.5。将该约束转化为单一价格上限即为格雷厄姆数，代表按格雷厄姆标准能接受的最高价格。

### 计算公式

$$\text{Graham Number} = \sqrt{22.5 \times EPS \times BVPS}$$

保守区间：

$$\text{低端} = \sqrt{20.0 \times EPS \times BVPS}, \quad \text{高端} = \sqrt{25.0 \times EPS \times BVPS}$$

### 因子含义

| 变量 | 含义 | 注意事项 |
|------|------|---------|
| EPS | 每股收益（最新年度） | 必须为正，否则公式无意义 |
| BVPS | 每股账面价值 | 必须 ≥ 10 元/美元；轻资产公司（大量回购后）可能极低，导致结果失真 |
| 22.5 | P/E × P/B 乘积上限 | 来自 P/E=15 × P/B=1.5 的约束 |

### 配置参数与默认值

| 参数 | 默认值 | 说明 |
|------|-------|------|
| `BVPS_THRESHOLD` | 10.0 | BVPS 低于该值判定为轻资产公司，拒绝计算 |
| 低端系数 | 20.0 | 对应 P/E=14 × P/B=1.43 的更保守约束 |
| 高端系数 | 25.0 | 对应 P/E=15 × P/B=1.67 的略宽松约束 |

### 方法局限性

- **轻资产公司不适用**：大量股票回购（如贵州茅台、茅台的 BVPS 因历史积累较高但许多科技股会趋近于零）、无形资产为主的公司，BVPS 无法反映真实资产价值。
- **忽略增长**：公式不考虑未来增长，对高成长股严重低估。
- **不适用金融股**：银行、保险公司的盈利模式和杠杆结构与制造业根本不同。
- **静态快照**：仅基于当期数据，不考虑盈利周期性（周期顶峰 EPS 会严重高估格雷厄姆数）。

### 案例 A：看多——中国神华（601088）

**假设数据（2024 年报）**：
- EPS = 3.20 元
- BVPS = 22.50 元
- 当前股价 = 32.00 元

**计算**：
```
Graham Number = √(22.5 × 3.20 × 22.50) = √(1620) ≈ 40.25 元
溢价/折价 = (40.25 - 32.00) / 32.00 × 100% ≈ +25.8%（低估）
```

**信号**：当前股价较格雷厄姆数低约 26%，P/E ≈ 10x，P/B ≈ 1.42x，符合"P/E×P/B ≤ 22.5"的双重安全边际。神华为资产密集型能源企业，账面价值真实，盈利稳定，格雷厄姆数在此场景有效。

### 案例 B：看空/不适用——宁德时代（300750）

**假设数据（2024 年报）**：
- EPS = 10.50 元
- BVPS = 88.00 元（高于阈值，公式可计算）
- 当前股价 = 220.00 元

**计算**：
```
Graham Number = √(22.5 × 10.50 × 88.00) = √(20790) ≈ 144.2 元
溢价 = (144.2 - 220.00) / 220.00 × 100% ≈ -34.5%（高估信号）
```

**局限**：格雷厄姆数提示高估，但宁德时代的竞争护城河、全球市占率扩张、电池技术优势均未纳入考量。该公式将一家仍处于快速成长期的全球龙头企业等同于静态资产，得出的"高估"结论需结合 DCF 等动态模型验证，不能直接排除买入。

## 2. Graham Formula（格雷厄姆成长公式）

### 适用场景

适用于**有稳定盈利、增长率适中（5%–15%）的成熟企业**。格雷厄姆在 1962 年版《证券分析》中引入该公式，用于将成长因子纳入估值。

### 方法描述

在格雷厄姆数的基础上引入预期增长率 `g`，并以当期 AAA 级债券收益率 `Y` 锚定利率环境，将不同利率环境下的估值进行标准化。

### 计算公式

$$V = \frac{EPS \times (8.5 + 2g) \times 4.4}{Y}$$

其中：
- 4.4 为格雷厄姆写作时（1962 年）的 AAA 债券基准收益率
- Y 为当前 AAA 级企业债收益率

### 因子含义

| 变量 | 含义 | 注意事项 |
|------|------|---------|
| EPS | 每股收益 | 必须为正 |
| 8.5 | 零增长公司的合理基础 P/E | 格雷厄姆时代的市场共识 |
| 2g | 每 1% 增长贡献 2 倍 P/E | g 上限 20%，下限 0% |
| 4.4 | 历史基准债券收益率 | 常数，不变 |
| Y | 当前 AAA 级债券收益率 | A 股默认 5.30%（`aaa_corporate_yield`） |

### 配置参数与默认值

| 参数 | 默认值 | 说明 |
|------|-------|------|
| `growth_cap` | 20.0% | 增长率上限，防止极端输入 |
| `MIN_GROWTH` | 0.0% | 增长率下限（负增长公司不适用） |
| `aaa_corporate_yield` | 5.30% | 默认 Y 值（可配置） |

### 方法局限性

- **增长率估计高度主观**：g 的取值对结果影响极大（g 从 10% 升至 15%，公式值上涨约 29%）。
- **8.5 的基础 P/E 已过时**：该数字来自 20 世纪 60 年代，当前低利率或高利率环境下未必合理。
- **分母 Y 的代表性**：A 股不存在真正的 AAA 企业债市场，通常用 AAA 城投债或优质信用债代替，存在市场分割问题。
- **不适用高增长或周期股**：增长率超过 20% 被强制截断，且周期顶峰 EPS 会大幅高估价值。

### 案例 A：看多——格力电器（000651）

**假设数据（2024 年报）**：
- EPS = 5.80 元
- 预期 5 年增长率 g = 8%（空调行业稳健增长）
- Y（AAA 债券收益率）= 5.30%
- 当前股价 = 38.00 元

**计算**：
```
V = (5.80 × (8.5 + 2×8) × 4.4) / 5.30
  = (5.80 × 24.5 × 4.4) / 5.30
  = (625.24) / 5.30
  ≈ 117.97 元
```

**信号**：公式内在价值约 118 元，远高于当前 38 元，折价约 68%。格力有稳定的分红记录和可预测的空调业务，g = 8% 的假设较为保守，该公式输出高度低估信号，与 DDM/EPV 结果可相互印证。

### 案例 B：看空/不适用——某互联网平台公司（假设）

**假设数据**：
- EPS = 2.00 元
- 预期增长率 = 35%（被截断至 20%）
- Y = 5.30%
- 当前股价 = 180.00 元

**计算**：
```
V = (2.00 × (8.5 + 2×20) × 4.4) / 5.30
  = (2.00 × 48.5 × 4.4) / 5.30
  ≈ 80.45 元（已截断增长率后）
```

**局限**：公式因增长率被截断而严重低估互联网平台的真实价值。35% 的实际增长率意味着公司具备平台网络效应，这部分价值无法在 Graham Formula 中体现。此外，8.5 的基础 P/E 对互联网商业模式根本不适用。

## 3. NCAV（Net-Net 清算价值）

### 适用场景

适用于**深度价值/"雪茄烟蒂"投资**，即寻找股价低于清算价值的极度低估股票。格雷厄姆认为以低于 NCAV 2/3 的价格买入是最保守的安全边际策略。

### 方法描述

NCAV（净流动资产价值）假设公司在清算情景下，固定资产和长期资产价值为零，仅用流动资产偿还全部负债。这是一种极端保守的"悲观清算"假设。

### 计算公式

$$NCAV = \frac{\text{流动资产} - \text{全部负债} - \text{优先股}}{股数}$$

**买入目标价**（格雷厄姆 2/3 原则）：

$$P_{\text{buy}} = NCAV \times 0.67$$

**变体（保守清算价值）**：

$$NCAV_{\text{conservative}} = \frac{0.85 \times \text{流动资产} - \text{全部负债} - \text{优先股}}{股数}$$

> 打折 85% 以反映流动资产（应收账款、存货等）的变现损耗。

### 因子含义

| 变量 | 含义 |
|------|------|
| 流动资产 | 现金、应收账款、存货等一年内可变现资产 |
| 全部负债 | 流动负债 + 长期负债（注意：非仅流动负债） |
| 优先股 | 优先股清算价值（有则扣除） |
| 股数 | 流通股股数（摊薄后） |

### 配置参数与默认值

| 参数 | 默认值 | 说明 |
|------|-------|------|
| `preferred_stock` | 0.0 | 优先股清算价值（默认无） |
| `safety_margin` | 0.67 | 买入目标价为 NCAV 的 2/3 |

### 方法局限性

- **A 股几乎找不到**：成熟市场极少出现真实的 Net-Net 机会，A 股退市制度改革后更少，反而可能是"清算陷阱"（公司持续亏损、资产品质差）。
- **流动资产质量参差不齐**：高存货占比（如钢铁、房地产）的流动资产变现价值可能远低于账面值。
- **静态时间点**：仅看某一时点的资产负债表，不考虑持续亏损速度，公司可能在被清算前把 NCAV "烧光"。
- **管理层风险**：即使存在清算价值，控股股东未必愿意清算，价值可能永远无法实现（尤其 A 股）。

### 案例 A：看多——某 A 股制造小盘股（假设）

**假设数据**：
- 流动资产 = 5.0 亿元
- 全部负债 = 1.8 亿元
- 优先股 = 0
- 流通股 = 1.0 亿股
- 当前股价 = 2.50 元

**计算**：
```
NCAV 总额 = 5.0 - 1.8 - 0 = 3.2 亿元
NCAV 每股 = 3.2 / 1.0 = 3.20 元
买入目标 = 3.20 × 0.67 = 2.14 元
当前价 2.50 元 > 2.14 元，但低于 3.20 元（NCAV 折价 22%）
```

**信号**：股价位于 NCAV 与 2/3 NCAV 之间，属于较有吸引力的区域，尤其若公司 FCF 为正（非持续烧钱），此时买入具有较强安全边际。

### 案例 B：看空/不适用——某亏损零售商

**假设数据**：
- 流动资产 = 8.0 亿元（其中 6.5 亿为高周转但季节性强的服装存货）
- 全部负债 = 6.5 亿元
- NCAV 每股 = 1.50 元，股价 = 0.90 元（低于 NCAV）

**局限**：表面上满足 Net-Net 标准，但存货变现时打五折则实际 NCAV 接近于零。加之零售行业持续亏损，NCAV"被烧光"的速度可能超过投资者等待清算的耐心。这是典型的 NCAV 陷阱。

## 第二组：DCF 体系

---

## 4. DCF（10 年自由现金流折现）

### 适用场景

适用于**自由现金流可预测、正值且较为稳定的企业**，包括成熟消费品、工业龙头、科技平台等。是最严谨的内在价值估算方法，也是机构投资者的核心估值工具。

### 方法描述

将企业未来 10 年的预期自由现金流逐年折现至现在，加上第 10 年之后的永续增长"终值"，得到企业价值，再减去净负债得到股权价值，最终除以股数得到内在价值每股。

### 计算公式

**三阶段增长模型**：

$$FCF_t = FCF_0 \times \prod_{i=1}^{t}(1 + g_i), \quad g_i = \begin{cases} g_1 & t \leq 5 \\ g_2 & 6 \leq t \leq 10 \end{cases}$$

**10 年现值之和**：

$$PV_{\text{FCF}} = \sum_{t=1}^{10} \frac{FCF_t}{(1 + r)^t}$$

**终值**（Gordon 增长模型）：

$$TV = \frac{FCF_{10} \times (1 + g_{\text{terminal}})}{r - g_{\text{terminal}}}$$

**企业价值与股权价值**：

$$EV = PV_{\text{FCF}} + \frac{TV}{(1+r)^{10}}$$

$$\text{内在价值} = \frac{EV - \text{净负债}}{\text{股数}}$$

### 因子含义

| 变量 | 含义 |
|------|------|
| $FCF_0$ | 当期自由现金流（经营现金流 - 资本支出） |
| $g_1$ | 第 1-5 年 FCF 年增长率 |
| $g_2$ | 第 6-10 年 FCF 年增长率（通常低于 g₁） |
| $g_{\text{terminal}}$ | 永续增长率（不得超过长期名义 GDP 增速） |
| $r$ | 折现率（WACC） |
| 净负债 | 有息负债 - 现金及等价物 |

### 配置参数与默认值

| 参数 | 默认值 | 说明 |
|------|-------|------|
| `growth_rate_1_5` | 5.0% | 第 1-5 年增长率 |
| `growth_rate_6_10` | 3.0% | 第 6-10 年增长率 |
| `terminal_growth` | 2.0% | 永续增长率 |
| `discount_rate` | 10.0% | WACC（可由 CAPM 计算） |
| 敏感性低端 | g1-2%, g2-1%, gT-0.5%, r+2% | 悲观情景 |
| 敏感性高端 | g1+2%, g2+1%, gT+0.5%, r-2% | 乐观情景 |

### 方法局限性

- **终值主导估值**：当终值占企业价值 > 60% 时，模型对永续增长率极度敏感（0.5% 的差异可使估值变化 10-15%）。
- **FCF 可预测性要求高**：不适用于银行（用利润而非 FCF）、早期亏损公司、极度周期性行业。
- **WACC 估算主观**：β 值来源不同、风险溢价假设不同，可能导致 WACC 差异 2-3 个百分点，进而使估值相差 30-50%。
- **"垃圾进、垃圾出"**：增长率假设的合理性决定结果，建议与 Reverse DCF 联合使用以验证市场隐含增长假设。

### 案例 A：看多——贵州茅台（600519）

**假设数据（2024 年报）**：
- 当期 FCF = 680 亿元（经营现金流 750 亿 - 资本支出 70 亿）
- 净负债 = -1200 亿元（净现金）
- 流通股 = 12.56 亿股

**参数假设**：
- g1 (1-5 年) = 8%（量价双升逻辑）
- g2 (6-10 年) = 5%（高端白酒增速放缓）
- g_terminal = 2.5%（名义 GDP 下沿）
- WACC = 9.0%

**计算（简化）**：

```
PV(FCF年1-10) ≈ 680 × [第1-5年 8% 增长 + 第6-10年 5% 增长，折现] ≈ 5,850 亿元
FCF_10 ≈ 680 × 1.08^5 × 1.05^5 ≈ 1,460 亿元
TV = 1,460 × 1.025 / (0.09 - 0.025) ≈ 23,015 亿元
PV(TV) = 23,015 / 1.09^10 ≈ 9,720 亿元

EV = 5,850 + 9,720 = 15,570 亿元
股权价值 = 15,570 + 1,200 = 16,770 亿元
内在价值/股 = 16,770 / 12.56 ≈ 1,335 元
```

若当前股价约 1,100 元，折价约 21%，DCF 给出低估信号。

### 案例 B：看空/不适用——某亏损科技初创公司

**问题**：FCF 为负（-15 亿元），公司烧钱阶段，无法使用正 FCF 起点进行 DCF。即使强行预测"5 年后盈利"，增长率假设的不确定性使整个模型变为纯粹的想象力竞赛，置信度极低。此类公司更适合用 Reverse DCF 反推：当前股价隐含了什么样的增长假设，再判断这一假设是否可信。

## 5. Reverse DCF（反推隐含增长率）

### 适用场景

适用于**高估值成长股**的理性检视，不给出"买"或"卖"的结论，而是揭示：**按当前股价，市场究竟预期该公司未来增长多少**。若隐含增长率远超合理范围，则说明股价充分反映甚至透支了乐观预期。

### 方法描述

以当前股价为目标，反向求解 DCF 方程，通过二分法迭代找出使企业价值等于当前市值的隐含增长率 g₁（第 6-10 年增长率设为 g₁ × 0.5）。

### 计算公式

求解使下式成立的 g₁：

$$\text{当前市值} + \text{净负债} = \sum_{t=1}^{10} \frac{FCF_0 \times \prod(1+g_t)}{(1+r)^t} + \frac{FCF_{10} \times (1+g_{\text{terminal}})}{(r - g_{\text{terminal}}) \times (1+r)^{10}}$$

其中第 6-10 年增长率 = $g_1 \times 0.5$（内置假设，可调）。

**迭代参数**：
- 最大迭代次数：200
- 增长率搜索范围：`[-10%, 100%]`
- 收敛精度：相对误差 < 0.1%

### 因子含义

| 变量 | 含义 |
|------|------|
| 当前市值 | 股价 × 流通股数 |
| 净负债 | 用于还原企业价值 |
| g₁（隐含） | 市场定价隐含的未来 5 年 FCF 年增长率 |
| r | 折现率（与 DCF 保持一致） |

### 配置参数与默认值

| 参数 | 默认值 | 说明 |
|------|-------|------|
| `discount_rate` | 10.0% | 折现率（与正向 DCF 一致） |
| `terminal_growth` | 2.0% | 永续增长率 |
| `MAX_ITERATIONS` | 200 | 二分法最大迭代次数 |

### 方法局限性

- **结果不是估值**：Reverse DCF 不告诉你公司值多少钱，只告诉你市场认为它值多少钱。需要独立判断隐含假设是否合理。
- **FCF 起点影响大**：若当期 FCF 是异常高峰值（如一次性处置收益），计算出的隐含增长率会偏低，形成假性"增长要求不高"的错觉。
- **不适用负 FCF 公司**：FCF 为负时方程无解。

### 案例 A：看多——招商银行（600036，工具用途）

由于银行不适用 DCF，此场景用来说明 Reverse DCF 的**工具价值**：分析师可以用该工具评估"当前股价已隐含了多少坏账预期下的 FCF 萎缩"，辅助判断悲观预期是否过度。

### 案例 B：看空信号——某热门半导体公司

**假设数据**：
- 当期 FCF = 5 亿元
- 净负债 = -20 亿元（净现金）
- 流通股 = 10 亿股
- 当前股价 = 120 元（对应市值 1,200 亿元）
- WACC = 10%

**结果**：Reverse DCF 反推隐含 g₁ ≈ 45%，意味着市场预期该公司未来 5 年 FCF 年增长 45%。

**判断**：45% 的 FCF 年增速维持 5 年，需要极强的技术护城河和持续扩张的市场空间。对于大多数半导体公司，这一要求极高，任何技术迭代失误、客户集中风险或行业周期下行都会使这一假设落空，股价面临大幅回调风险。

## 第三组：盈利力价值

---

## 6. EPV（零增长盈利力价值）

### 适用场景

适用于**具有可持续竞争优势的成熟企业**，尤其适合用来判断企业的"底线价值"——即假设公司不再增长，当前盈利能力能支撑多高的股价。由哥伦比亚大学 Bruce Greenwald 教授系统化。

### 方法描述

EPV 从 EBIT 出发，扣除税收和维护性资本支出（保持当前竞争地位所必须的支出），得到可分配给股东的"真实正常化盈利"，再除以资本成本折现为永续年金价值。市值高于 EPV 意味着市场在为未来增长付费，EPV 构成价值投资的"零增长地板价"。

### 计算公式

**步骤 1：正常化 EBIT**：

$$EBIT = \text{Revenue} \times \text{Operating Margin}$$

**步骤 2：税后净营业利润**：

$$NOPAT = EBIT \times (1 - \text{Tax Rate})$$

**步骤 3：超额折旧调整**（Greenwald 方法）：

$$\text{超额折旧} = \text{Depreciation} \times (0.5 \times \text{Tax Rate})$$

> 理论依据：折旧中的税盾效应按税率的 50% 折算（保守估计实际税盾利用率）。

**步骤 4：可分配现金流**：

$$DCF_{\text{distributable}} = NOPAT - \text{维护性CapEx} + \text{超额折旧}$$

其中：维护性 CapEx = 总 CapEx × 70%（默认 70% 为维护性）

**步骤 5：EPV**：

$$EPV_{\text{operating}} = \frac{DCF_{\text{distributable}}}{\text{Cost of Capital}}$$

$$EPV_{\text{per share}} = \frac{EPV_{\text{operating}} - \text{净负债}}{\text{股数}}$$

### 因子含义

| 变量 | 含义 |
|------|------|
| Revenue × Op. Margin | 正常化营业利润（抹平周期波动） |
| Tax Rate | 有效税率（A 股默认 25%） |
| Depreciation | 当年折旧（来自现金流量表） |
| CapEx | 资本支出（全部，包括增长性支出） |
| 维护性 CapEx 比例 | 默认 70%（可配置），代表维持现有业务的支出比例 |
| Cost of Capital | 加权平均资本成本（WACC） |

### 配置参数与默认值

| 参数 | 默认值 | 说明 |
|------|-------|------|
| `maintenance_capex_pct` | 0.70 | 维护性资本支出占总资本支出的比例 |
| `cost_of_capital` | 10.0% | 资本成本（A 股默认） |

### 方法局限性

- **不适用成长期公司**：零增长假设对高速扩张企业严重低估，EPV 是价值的下限，不是上限。
- **操作利润率需正常化**：若使用周期顶峰的利润率，EPV 会虚高；应使用 5 年平均或正常化利润率。
- **维护性 CapEx 估算困难**：公司不在财报中区分"维护性"与"增长性"资本支出，70% 是经验假设，重资产行业（如钢铁）可能高达 85-90%。
- **不适用银行和金融股**：银行的"CapEx"概念不适用，应使用 PB/RI 模型。

### 案例 A：看多——长江电力（600900）

**假设数据（2024 年报）**：
- 营业收入 = 950 亿元，营业利润率 = 48%
- EBIT = 456 亿元
- 税率 = 15%（水电税收优惠）
- 折旧 = 120 亿元
- CapEx = 80 亿元（水电站为成熟资产，维护性比例高）
- WACC = 6%（低风险公用事业）
- 净负债 = 1,200 亿元
- 流通股 = 233 亿股

**计算**：
```
NOPAT = 456 × (1 - 15%) = 387.6 亿元
维护性CapEx = 80 × 70% = 56 亿元
超额折旧 = 120 × (50% × 15%) = 9 亿元
DCF_distributable = 387.6 - 56 + 9 = 340.6 亿元
EPV_operating = 340.6 / 6% = 5,677 亿元
EPV 每股 = (5,677 - 1,200) / 233 ≈ 19.22 元
```

若当前股价 16.5 元，EPV 折价约 16%，市场并未为增长溢价，具有合理安全边际。

### 案例 B：看空/不适用——某处于快速扩张期的连锁餐饮企业

公司当前利润率仅 3%（低于成熟期正常水平 8-10%），CapEx 中 70% 以上用于新店开张（增长性支出），EPV 计算出的"零增长价值"远低于当前股价。这不是"高估"，而是 EPV 本就不适合评估仍在烧钱扩张的成长期企业。

## 7. Owner Earnings（巴菲特所有者收益）

### 适用场景

适用于**现金流质量评估和内在价值计算**，尤其适合评估"报告盈利与真实可分配盈利差距大"的企业，如大量折旧摊销的老牌企业或 NWC 持续增加的扩张型企业。

### 方法描述

巴菲特在 1986 年股东信中定义所有者收益为："报告盈利 + 折旧等非现金费用 - 维护性资本支出 - 营运资本变化"，代表股东真正可以拿走而不损害公司竞争地位的现金量。

### 计算公式

$$OE = \text{净利润} + \text{折旧} - \text{维护性CapEx} - \Delta NWC$$

**内在价值（零增长与有增长的平均值）**：

$$IV_{\text{zero}} = \frac{OE / \text{股数}}{\text{资本成本}}$$

$$IV_{\text{growth}} = \frac{(OE / \text{股数}) \times (1 + g)}{\text{资本成本} - g}$$

$$\text{公允价值} = \frac{IV_{\text{zero}} + IV_{\text{growth}}}{2}$$

### 因子含义

| 变量 | 含义 |
|------|------|
| 净利润 | GAAP 报告盈利 |
| 折旧 | 折旧与摊销（D&A），非现金费用加回 |
| 维护性 CapEx | 总资本支出 × 70%（保持竞争力必须的支出） |
| ΔNWC | 营运资本变化（NWC 增加消耗现金，需从 OE 中扣除） |
| g | 预期永续增长率（使用 `growth_rate` 字段） |

**盈利质量指标**：

$$\text{盈利质量} = \frac{OE}{\text{净利润}}$$

- > 1.2：现金转化优异（高质量）
- 0.8–1.2：正常范围
- < 0.7：盈利质量较差，应引起警惕

### 配置参数与默认值

| 参数 | 默认值 | 说明 |
|------|-------|------|
| `maintenance_capex_pct` | 0.70 | 维护性 CapEx 占比 |
| `DEFAULT_DEPRECIATION_PCT` | 5% of Revenue | 折旧数据缺失时的估算比例 |
| `DEFAULT_CAPEX_PCT` | 7% of Revenue | CapEx 数据缺失时的估算比例 |
| `DEFAULT_NWC_CHANGE_PCT` | 1% of Revenue | NWC 变化数据缺失时的估算比例 |

### 方法局限性

- **NWC 变化估算粗糙**：精确计算需要历年 NWC 数据，单年度的 NWC 变化可能因季节性大幅波动，干扰 OE 的准确性。
- **维护性 vs 增长性 CapEx 难以区分**：同 EPV，企业不公开这一拆分，70% 的假设因行业不同可能相差悬殊。
- **对制造业以外行业需调整**：轻资产服务业（如软件公司）的折旧远低于实际维护成本；金融业的"CapEx"概念完全不适用。

### 案例 A：看多——贵州茅台（600519）

**假设数据**：
- 净利润 = 740 亿元
- D&A = 35 亿元（酒厂物理资产折旧）
- 总 CapEx = 45 亿元，维护性 CapEx = 45 × 70% = 31.5 亿元
- ΔNWC ≈ 20 亿元（预收货款增加，实为负 NWC 变化，对 OE 有利）
- 流通股 = 12.56 亿股

```
OE = 740 + 35 - 31.5 - (-20) = 763.5 亿元（NWC 减少加回）
OE 每股 = 763.5 / 12.56 ≈ 60.79 元
盈利质量 = 763.5 / 740 ≈ 1.03（高质量，现金转化略超报告盈利）
IV(零增长, WACC=9%) = 60.79 / 9% ≈ 675 元
IV(4%增长) = 60.79×1.04 / (9%-4%) ≈ 1,265 元
公允价值 ≈ (675 + 1,265) / 2 ≈ 970 元
```

### 案例 B：看空/不适用——某重资产扩张型企业

公司净利润 50 亿，D&A 高达 80 亿（大量折旧），CapEx 却高达 200 亿（主要为增长性投资）。若使用 70% 比例，维护性 CapEx = 140 亿，OE = 50 + 80 - 140 = -10 亿元（负值）。Owner Earnings 为负说明公司盈利是"会计利润"，真正可分配给股东的现金为负，该模型无法给出有效估值。

## 第四组：股息模型

---

## 8. DDM（Gordon 增长模型）

### 适用场景

适用于**稳定分红的公用事业、银行优先股、REITs、成熟消费品企业**。要求股息有历史记录、增长率可预测，且增长率显著低于权益成本。

### 方法描述

Gordon 增长模型假设股息以固定速率永续增长，公司价值等于下一期股息除以"权益成本减去股息增长率"的差。

### 计算公式

$$P = \frac{D_1}{r - g} = \frac{D_0 \times (1 + g)}{r - g}$$

**当前收益率与公允收益率对比**：

$$\text{当前股息率} = \frac{D_0}{P_{\text{current}}}, \quad \text{公允股息率} = \frac{D_1}{P_{\text{fair}}} = r - g$$

### 因子含义

| 变量 | 含义 |
|------|------|
| $D_0$ | 当期每股股息（最新年报） |
| $D_1$ | 下一期预期股息 = D₀ × (1+g) |
| $r$ | 权益成本（Cost of Equity，使用 `cost_of_capital` 字段） |
| $g$ | 股息年增长率（`dividend_growth_rate`，默认 3%，上限 15%） |

**关键约束**：$r > g$，否则公式无意义（股息增速超过折现率时，公司理论价值趋向无穷大）。

### 配置参数与默认值

| 参数 | 默认值 | 说明 |
|------|-------|------|
| `dividend_growth_rate` | 3.0% | 股息增长率 |
| `cost_of_capital` | 10.0% | 权益成本 |
| `MAX_GROWTH_RATE` | 15.0% | 增长率超过此值发出警告 |
| `required_return`（可覆盖）| None | 若指定则覆盖 cost_of_capital |

### 方法局限性

- **对 r-g 差值极度敏感**：当 r=8%，g=6% 时，分母仅 2%，g 增加 1%（至 7%）会使估值翻倍。
- **不适用不分红或分红不规律的公司**：约一半 A 股不分红或分红比例极低（如早期成长型企业）。
- **高派息率陷阱**：派息率超过 80% 时，股息依赖存量盈利而非增量增长，增长率假设可能不可持续。
- **忽略回购**：部分优质企业选择回购而非分红返还股东，DDM 会系统性低估此类公司价值。

### 案例 A：看多——长江电力（600900）

**假设数据（2024 年报）**：
- D₀ = 0.83 元/股
- g = 4.0%（水电量增+水价上调逻辑）
- r = 7.5%（公用事业低风险 CAPM）
- 当前股价 = 16.5 元

**计算**：
```
D₁ = 0.83 × 1.04 = 0.8632 元
P = 0.8632 / (7.5% - 4.0%) = 0.8632 / 3.5% ≈ 24.66 元
溢价/折价 = (24.66 - 16.5) / 16.5 ≈ +49%（明显低估）
当前股息率 = 0.83 / 16.5 ≈ 5.0%，公允股息率 = 3.5%
```

DDM 给出强烈低估信号，且当前 5.0% 股息率显著高于公允的 3.5%。长电现金流稳定、分红历史清晰，DDM 在此高度适用。

### 案例 B：看空/不适用——某高周期股分红

某钢铁公司 2021 年暴利期 D₀ = 2.0 元，市场情绪高涨，g = 8% 被视为保守，DDM 给出公允价 = 2.16 / (9% - 8%) = 216 元。然而 2023 年钢价回落，EPS 腰斩，股息仅 0.30 元，无论用任何合理参数，股价都无法支撑 216 元的估值。**DDM 最大的陷阱：将周期峰值股息投射为永续增长**。

## 9. Two-Stage DDM（两阶段股息折现）

### 适用场景

适用于**当前处于较高增速、预期未来降速至成熟期永续增长的分红企业**，如银行、险资、大型消费品企业。比单阶段 DDM 更贴近实际企业生命周期。

### 方法描述

将股息增长分为两个阶段：第一阶段（默认 5 年）采用较高增长率 g₁，逐年折现；第二阶段从第 6 年起采用永续增长率 g₂，以 Gordon 公式计算终值再折现到现在。

### 计算公式

**第一阶段（年 1 至 n）**：

$$PV_1 = \sum_{t=1}^{n} \frac{D_0 \times (1+g_1)^t}{(1+r)^t}$$

**第二阶段终值**：

$$TV = \frac{D_n \times (1 + g_2)}{r - g_2}, \quad PV_2 = \frac{TV}{(1+r)^n}$$

**总价值**：

$$P = PV_1 + PV_2$$

### 因子含义

| 变量 | 含义 |
|------|------|
| $g_1$ | 第一阶段高速增长率（默认 5.0%） |
| $n$ | 第一阶段持续年数（默认 5 年） |
| $g_2$ | 永续增长率（默认 2.0%） |
| $r$ | 权益成本（同 DDM） |

### 配置参数与默认值

| 参数 | 默认值 | 说明 |
|------|-------|------|
| `growth_stage1` | 5.0% | 第一阶段增长率 |
| `stage1_years` | 5 | 第一阶段年数 |
| `growth_stage2` | 2.0% | 永续增长率 |

**风险警示**：终值占总价值比例 > 70% 时，模型对 g₂ 和 r 的小幅变化高度敏感，置信度降低。

### 方法局限性

同 DDM，但额外风险在于：
- **阶段分界点主观**：5 年是经验假设，具体企业可能 3 年就进入成熟期或 8 年仍保持高速。
- **g₁ 到 g₂ 的突变假设**：现实中增长通常是平滑下降的，两阶段模型的阶跃可能引入系统误差。
- **更复杂不代表更准确**：额外参数增加了调参空间，反而可能引入更多主观性。

### 案例 A：看多——招商银行（600036）

**假设数据（2024 年报）**：
- D₀ = 1.97 元（2024 年报分红）
- r = 9.5%（银行权益成本，含信用风险溢价）
- g₁ = 7%（零售银行 ROE 维持高位，分红比例稳定）
- 第一阶段 = 5 年
- g₂ = 3%（长期与名义 GDP 锚定）
- 当前股价 = 40.0 元

```
PV₁ = Σ D₀×1.07^t / 1.095^t (t=1..5)
    ≈ 2.11+2.15+2.19+2.23+2.28 ≈ 10.96 元（折现后）
D₅ = 1.97 × 1.07^5 ≈ 2.76 元
TV = 2.76×1.03 / (9.5%-3%) = 2.84/6.5% ≈ 43.7 元
PV₂ = 43.7 / 1.095^5 ≈ 27.97 元
P = 10.96 + 27.97 ≈ 38.93 元
```

当前 40 元基本接近公允价值，无重大折价也无重大溢价，但若银行进一步提升分红比例（从 35% 至 40%），重新计算 D₀ 后有约 15% 低估空间。

### 案例 B：看空——某分红不可持续的周期股

派息率 90%（已达上限），g₁ = 6% 的假设要求 EPS 同步增长 6%。但行业处于下行周期，EPS 大概率下降，公司为维持股息可能借债分红。一旦削减股息，Two-Stage DDM 的所有参数都需重估，而股价通常在股息削减公告后立刻大跌 20-30%。

## 10. PB Valuation（P/B 模型）

### 适用场景

**银行、保险、金融控股等以资本密集型运营为核心的金融机构**。金融业的"生产资料"是资本，ROE 代表资本利用效率，P/B 模型通过 ROE 与权益成本的关系导出合理市净率。

### 方法描述

超额回报理论：一家 ROE 超过权益成本（COE）的公司，每增加一单位账面价值就能创造正的经济价值，因此理应以大于 1 的 P/B 溢价交易；反之若 ROE < COE，合理 P/B 小于 1。合理 P/B 的数学表达式来自 Gordon 增长模型的变形。

### 计算公式

$$\text{合理 P/B} = \frac{ROE - g}{COE - g}$$

$$\text{公允价格} = BVPS \times \text{合理 P/B}$$

### 因子含义

| 变量 | 含义 |
|------|------|
| ROE | 净资产收益率（净利润/平均净资产） |
| g | 可持续增长率（= ROE × 留存率） |
| COE | 权益成本（CAPM 或直接设定，默认 10%） |
| BVPS | 每股账面价值（净资产/股数） |

**经济学直觉**：当 ROE = COE 时，合理 P/B = 1（无超额回报，账面价值就是公允价值）。

### 配置参数与默认值

| 参数 | 默认值 | 说明 |
|------|-------|------|
| `cost_of_equity` | 10.0% | 权益成本 COE |
| `sustainable_growth` | 2.0% | 可持续增长率 g |

### 方法局限性

- **仅适用金融股**：轻资产科技公司的 BVPS 因大量回购可能极低，P/B 模型完全失效。
- **ROE 的周期性**：银行 ROE 在信用周期高峰可达 15-18%，低谷可跌至 10% 以下，使用峰值 ROE 会高估公允 P/B。
- **账面价值可能被侵蚀**：不良贷款若未充分拨备，BVPS 是虚高的，公允价格估算因此不可靠。
- **利率环境敏感性**：COE 随利率变化，利率上行导致 COE 提高，公允 P/B 快速下降。

### 案例 A：看多——工商银行（601398）

**假设数据（2024 年报）**：
- BVPS = 9.80 元
- ROE = 11.5%
- COE = 9.0%（国有大行低风险，β ≈ 0.7）
- g = 3.0%（信贷规模适度扩张）
- 当前股价 = 5.80 元（P/B ≈ 0.59x）

**计算**：
```
合理 P/B = (11.5% - 3.0%) / (9.0% - 3.0%) = 8.5% / 6.0% = 1.42x
公允价格 = 9.80 × 1.42 ≈ 13.92 元
折价 = (13.92 - 5.80) / 5.80 ≈ -58%（严重低估）
```

当前 0.59x P/B 远低于合理 1.42x P/B，表明市场要么认为不良贷款大幅侵蚀 BVPS，要么认为未来 ROE 会下降至 COE 附近。若不良资产问题可控，该低估提供了显著的安全边际。

### 案例 B：看空/局限——某互联网平台

ROE = 35%，BVPS = 5 元（大量回购后），当前股价 = 300 元，P/B = 60x。公式给出合理 P/B = (35%-3%)/(12%-3%) = 3.56x，公允价格 = 5×3.56 = 17.8 元，似乎严重高估。实际上该平台的资产价值（用户数据、算法、品牌）根本无法体现在账面上，P/B 模型对轻资产互联网公司无效。

## 11. Residual Income（剩余收益模型）

### 适用场景

适用于**银行、保险、稳定分红的金融机构**，是金融行业专业分析师最常用的内在价值模型之一。剩余收益模型考虑了"超额 ROE"随时间均值回归的特性，比单纯 P/B 模型更完整。

### 方法描述

企业价值 = 当前账面价值 + 未来各期剩余收益（超额 ROE × 账面价值）的折现。剩余收益（RI）= 实际盈利 - 股东要求的最低回报（权益成本 × 账面价值）。当 ROE = COE 时，RI = 0，公司价值等于账面价值。

### 计算公式

$$RI_t = BVPS_t \times (ROE_t - COE)$$

$$V = BVPS_0 + \sum_{t=1}^{n} \frac{RI_t}{(1+COE)^t} + \frac{RI_{\text{terminal}}}{COE \times (1+COE)^n}$$

**账面价值动态更新**（各期末）：

$$BVPS_{t+1} = BVPS_t \times (1 + g_{\text{sustainable}})$$

其中 $g_{\text{sustainable}} = ROE \times (1 - \text{派息率})$

**终值剩余收益**（ROE 向 `terminal_roe` 均值回归）：

$$RI_{\text{terminal}} = BVPS_n \times (\text{terminal\_roe} - COE)$$

### 因子含义

| 变量 | 含义 |
|------|------|
| BVPS₀ | 当前每股账面价值 |
| ROE | 当前净资产收益率 |
| COE | 权益成本 |
| terminal_roe | 长期均值回归目标 ROE |
| payout_ratio | 股息派发率（影响账面价值增速） |

### 配置参数与默认值

| 参数 | 默认值 | 说明 |
|------|-------|------|
| `cost_of_equity` | 10.0% | 权益成本 |
| `years` | 10 | 显式预测期（年） |
| `terminal_roe` | 8.0% | 长期均值回归 ROE（低于当前） |
| `payout_ratio` | 0.60 | 股息派发率（影响 g_sustainable） |

### 方法局限性

- **ROE 均值回归速度难以估计**：模型假设 ROE 向 `terminal_roe` 均值回归，但银行的 ROE 若受政策利率、不良贷款双重影响，回归速度可能快于或慢于模型假设。
- **对 COE 敏感**：COE 每变化 1 个百分点，估值变化可达 10-20%。
- **账面价值质量**：若 BVPS 因信贷损失被高估，剩余收益的计算基础就不可靠。

### 案例 A：看多——招商银行（600036）

**假设数据**：
- BVPS = 38.5 元
- ROE = 16%，COE = 9.5%
- terminal_roe = 12%（长期竞争优势维持一定超额回报）
- payout_ratio = 35%，sustainable_g = 16% × 65% ≈ 10.4%

**定性结论**：ROE(16%) >> COE(9.5%)，超额 ROE = 6.5%，剩余收益为正且显著，公司价值将大幅高于账面价值。RI 模型会给出较高的内在价值，当前若 P/B < 1.5x，则存在低估空间。

### 案例 B：看空/局限——ROE 持续低于 COE 的地区银行

某城商行 ROE = 8%，COE = 10%，剩余收益为负（-2% × BVPS）。RI 模型给出的内在价值小于 BVPS，即合理估值低于 P/B = 1x，但当前股价在 P/B = 0.7x 也可能仍是高估——这就是价值陷阱：看似便宜（P/B < 1），但内在价值更低。

## 12. PEG Ratio

### 适用场景

适用于**盈利为正且增长稳定的成长股**（增长率 5%-50%），用于评估当前 P/E 是否相对于增长速度合理。PEG 是 Lynch 和 Fisher 等人推广的快速相对估值工具。

### 方法描述

PEG 通过将 P/E 除以增长率，标准化了不同增长速度公司的估值。PEG = 1 表示 P/E 与增长率匹配，PEG < 1 通常被视为低估，PEG > 2 通常被视为高估。

### 计算公式

$$PEG = \frac{P/E}{\text{增长率（\%）}}$$

**公允价格**（以 PEG = 1 为基准）：

$$P_{\text{fair}} = EPS \times \text{增长率} \times \text{目标 PEG（默认 1.0）}$$

### 因子含义

| 变量 | 含义 | 注意事项 |
|------|------|---------|
| P/E | 当前市盈率 = 股价/EPS | 必须为正 |
| 增长率 | 预期未来 3-5 年 EPS 年增长率 | 建议用 5 年平均预期，而非单年值 |
| 目标 PEG | 公允 PEG 倍数（默认 1.0） | 高质量成长股可用 1.5-2.0 |

**PEG 评估区间**：

| PEG 值 | 评估 |
|--------|------|
| < 1.0 | 低估 |
| 1.0–1.5 | 合理价值 |
| 1.5–2.0 | 轻微高估 |
| > 2.0 | 高估 |

### 配置参数与默认值

| 参数 | 默认值 | 说明 |
|------|-------|------|
| `fair_peg` | 1.0 | 目标 PEG（质量溢价时可调高） |
| `MIN_GROWTH` | 5.0% | 低于此值可靠性下降 |
| `MAX_GROWTH` | 50.0% | 超过此值发出警告 |

### 方法局限性

- **增长率估算高度主观**：使用历史增长率与分析师预期可能相差极大。
- **低增长公司不适用**：增长率 < 5% 时，PEG 分母趋于 0，数值失去意义。
- **不同行业 PEG 基准不同**：消费品 PEG=1 合理，银行股由于 P/E 天然偏低而 PEG 可能只有 0.5 但并不便宜。
- **忽略资产负债表**：高负债公司即使 PEG < 1 也可能是价值陷阱。

### 案例 A：看多——某消费品企业（假设）

- EPS = 3.0 元，当前股价 = 36 元，P/E = 12x
- 预期 5 年增长率 = 18%（品牌扩张）
- PEG = 12 / 18 = 0.67（低估信号）
- 公允价格 = 3.0 × 18 × 1.0 = 54 元（较当前 36 元有 50% 上行空间）

### 案例 B：看空——某高 P/E 成长股

- EPS = 1.0 元，股价 = 100 元，P/E = 100x
- 预期增长率 = 30%
- PEG = 100 / 30 = 3.33（明显高估）
- 即使将目标 PEG 放宽至 2.0（给予高质量溢价），公允价格 = 1.0 × 30 × 2.0 = 60 元，仍低于当前 100 元 40%。

## 13. GARP（合理价格成长）

### 适用场景

适用于**兼顾增长与合理估值的成长股筛选**，适合不愿接受极端高 P/E 但又寻求成长机会的投资者。GARP 是 Lynch 风格的主动管理策略。

### 方法描述

将未来 N 年（默认 5 年）的 EPS 增长投射到目标退出 P/E，再折现回当前，得到当前应支付的合理价格。结合了 DCF 的时间价值概念与 P/E 相对估值的直觉。

### 计算公式

$$EPS_N = EPS_0 \times (1 + g)^N$$

$$P_{\text{future}} = EPS_N \times P/E_{\text{target}}$$

$$P_{\text{fair}} = \frac{P_{\text{future}}}{(1 + r_{\text{required}})^N}$$

### 因子含义

| 变量 | 含义 |
|------|------|
| N | 预测期年数（默认 5 年） |
| g | 年均 EPS 增长率 |
| $P/E_{\text{target}}$ | 5 年后退出 P/E（默认 18x，行业合理水平） |
| $r_{\text{required}}$ | 要求回报率（默认 12%） |

### 配置参数与默认值

| 参数 | 默认值 | 说明 |
|------|-------|------|
| `target_pe` | 18x | 退出 P/E |
| `years` | 5 | 预测期 |
| `required_return` | 12.0% | 投资者要求回报率 |

### 方法局限性

- **目标 P/E 和预测期的选取主观性强**：目标 P/E 每差 2 倍，估值结果相差 20-30%。
- **线性外推增长**：假设增长率在整个预测期内保持不变，忽略了增长减速的可能。
- **双重折现错觉**：先用增长率放大未来 EPS，再折现回来，在数学上等价于一种特殊的 DCF，其隐含假设需要仔细审视。

### 案例 A：看多——迈瑞医疗（300760）（假设数据）

- EPS = 15.0 元，g = 20%，目标 P/E = 25x，要求回报 = 12%，N = 5 年
```
EPS₅ = 15.0 × 1.20^5 ≈ 37.3 元
P_future = 37.3 × 25 = 932.5 元
P_fair = 932.5 / 1.12^5 ≈ 529 元
```
若当前股价 350 元，GARP 给出约 51% 上行空间。

### 案例 B：看空——目标 P/E 高估失真

若将目标 P/E 设为 40x（而非行业平均 25x），上述计算公允价格立刻变为 1,490 元，任何公司都"看起来低估"。GARP 的危险在于：分析师倾向于将目标 P/E 设为当前 P/E，从而永远得出"合理"的结论。

## 14. Rule of 40（SaaS 健康度）

### 适用场景

**SaaS（软件即服务）、订阅制软件、云计算公司**的经营健康度评估工具。该规则认为：高速增长可以弥补低利润，高利润可以弥补低增长，两者之和达到 40% 即视为健康。

### 方法描述

Rule of 40 不是一个估值工具，而是**商业健康度的快速诊断器**。结合收入增速与 FCF 利润率，反映企业在增长与盈利之间的平衡能力。

### 计算公式

$$\text{Score} = \text{收入增长率（\%）} + \text{FCF 利润率（\%）}$$

其中 FCF 利润率 = FCF / Revenue × 100

**评级标准**：

| Score | 评级 | 说明 |
|-------|------|------|
| ≥ 50 | 卓越 | 增长与利润双优 |
| 40–50 | 健康 | 通过 Rule of 40 |
| 30–40 | 可接受 | 接近阈值，需关注 |
| 20–30 | 偏弱 | 有增长或盈利问题 |
| < 20 | 差 | 需要重大改善 |

### 因子含义

| 变量 | 含义 |
|------|------|
| 收入增长率 | 同比收入增长百分比 |
| FCF 利润率 | 自由现金流 / 营业收入 |

注：部分分析师用 EBITDA 利润率替代 FCF 利润率，应注意口径一致性。

### 配置参数与默认值

| 参数 | 默认值 | 说明 |
|------|-------|------|
| `min_score` | 40.0 | 健康度阈值（可调） |

### 方法局限性

- **无法给出股价目标**：Rule of 40 是诊断工具，不能直接用于估值，需结合 EV/Revenue、DCF 等。
- **不适用非 SaaS 行业**：传统制造业、零售业的利润率结构完全不同，Rule of 40 的阈值没有意义。
- **FCF vs EBITDA 口径不统一**：不同数据来源使用不同分子，比较时务必口径一致。
- **高增长期可能无 FCF**：初期 SaaS 公司 FCF 为负，Rule of 40 评分会偏低，不代表商业模式差。

### 案例 A：看多（健康）

某 SaaS 企业：收入增长 35%，FCF 利润率 12% → Score = 47，通过 Rule of 40，表明增长与盈利处于良性平衡。

### 案例 B：看空（不健康）

某企业：收入增长 15%，FCF 利润率 -5%（仍在亏损） → Score = 10，远低于 40 阈值，既无高速增长弥补亏损，也无高利润弥补低增长，SaaS 价值投资逻辑不成立。

## 15. EV/EBITDA

### 适用场景

适用于**高杠杆、重资产或跨境并购中的企业价值比较**，如电信、航空、基础设施、资源类企业。相比 P/E，EV/EBITDA 消除了资本结构差异，更适合对比不同负债率的公司。

### 方法描述

用企业价值（EV）除以息税折旧摊销前利润（EBITDA），得到"市场愿意为每单位 EBITDA 支付多少"，再用行业合理倍数反推公允 EV，减去净负债得到股权价值。

### 计算公式

$$EV = \text{市值} + \text{净负债} = \text{市值} + \text{有息负债} - \text{现金}$$

$$EV/EBITDA_{\text{current}} = \frac{EV}{EBITDA}$$

$$\text{公允 EV} = EBITDA \times \text{行业基准倍数}$$

$$\text{公允股价} = \frac{\text{公允 EV} - \text{净负债}}{\text{股数}}$$

### 因子含义

| 变量 | 含义 |
|------|------|
| EV | 企业价值（含债务，代表收购全部资产的成本） |
| EBITDA | 未扣除利息税收折旧摊销的盈利（近似于经营现金流） |
| 行业基准倍数 | 当前行业平均 EV/EBITDA |
| 净负债 | 有息负债 - 现金（注意：净负债为负表示净现金） |

**行业典型 EV/EBITDA 参考（默认值）**：

| 行业 | 典型倍数 |
|------|---------|
| 科技 | 15x |
| 医疗健康 | 12x |
| 消费 | 11x |
| 工业 | 9x |
| 公用事业 | 8x |
| 电信 | 6x |
| 能源 | 5x |
| 默认（未指定） | 10x |

### 配置参数与默认值

| 参数 | 默认值 | 说明 |
|------|-------|------|
| `fair_multiple` | None（使用行业默认） | 可手动指定目标倍数 |
| `industry` | None | 指定行业以使用对应默认倍数 |

**ROE > 20%** 时自动上调倍数 20%；**增长率 > 15%** 时上调 10%；**高杠杆（净负债/EV > 50%）** 时下调 15%。

### 方法局限性

- **不适用银行和金融机构**：EBITDA 对银行无意义，应使用 P/B/RI 模型。
- **EBITDA ≠ 自由现金流**：EBITDA 加回折旧，但折旧是真实资产消耗的会计反映，重资产企业若 CapEx 远高于折旧（即资产更新迭代快），EV/EBITDA 会系统性低估真实成本。
- **负 EBITDA 公司不适用**：亏损企业 EBITDA 为负时，倍数法无意义。
- **行业基准选择主观**：不同来源的行业平均值差异较大，需确保可比口径。

### 案例 A：看多——某电信运营商（假设）

- EBITDA = 300 亿元
- 净负债 = 500 亿元
- 流通股 = 200 亿股
- 当前股价 = 4.5 元，市值 = 900 亿元
- 当前 EV/EBITDA = (900+500)/300 = 4.67x

电信行业基准 6x，公允 EV = 300 × 6 = 1,800 亿元
公允股权价值 = 1,800 - 500 = 1,300 亿元
公允股价 = 1,300 / 200 = 6.50 元（较当前 4.5 元高 44%）

### 案例 B：看空——EBITDA 虚高

某航空公司 EBITDA = 100 亿（大量加回折旧），但 CapEx（飞机更新）= 150 亿，真实 FCF 为负。若投资者仅看 EV/EBITDA = 8x 认为"便宜"，却忽视持续需要大量资本投入的事实，则会陷入价值陷阱。

## 16. Magic Formula（Greenblatt 神奇公式）

### 适用场景

适用于**系统性筛选"质优价廉"股票组合**，由 Joel Greenblatt 在《股市稳赚》（2005）中提出。通过两个指标的综合排名实现批量选股，而非单股内在价值估算。

### 方法描述

将所有股票按两个指标排名，取排名之和最小的前 20-30 支股票构建组合：
1. **盈利率（Earnings Yield）** = EBIT / EV：衡量"每投入一单位企业价值能获取多少盈利"，是 P/E 的倒数版本，消除资本结构影响。
2. **资本回报率（ROC）** = EBIT / 投资资本：衡量"企业能以多高效率利用资本创造盈利"，反映护城河强度。

### 计算公式

$$\text{盈利率} = \frac{EBIT}{EV} \times 100\%$$

$$\text{资本回报率（ROC）} = \frac{EBIT}{\text{净固定资产} + \text{营运资本}} \times 100\%$$

$$\text{公允 EV}_{\text{基于盈利率}} = \frac{EBIT}{\text{要求盈利率（10\%）}}$$

$$\text{公允股价} = \frac{\text{公允 EV} - \text{净负债}}{\text{股数}}$$

### 因子含义

| 变量 | 含义 |
|------|------|
| EBIT | 息税前利润（剔除资本结构影响） |
| EV | 企业价值（市值+净负债） |
| 净固定资产 | PP&E（物业、厂房和设备）净值 |
| 营运资本 | 净营运资本（流动资产-流动负债） |
| 投资资本 | 净固定资产 + 营运资本 |

### 配置参数与默认值

| 参数 | 默认值 | 说明 |
|------|-------|------|
| `required_ey` | 10.0% | 要求最低盈利率（计算公允价的折现率） |
| `benchmark_roc` | 25.0% | ROC 基准（低于此值视为不优质） |

### 方法局限性

- **不适用金融股**：银行的"投资资本"和"EBIT"概念不适用。
- **负营运资本扭曲 ROC**：零售商（如超市）营运资本为负（先收款后付款），导致"投资资本"可能趋于零，ROC 趋于无穷大，排名失真。
- **需组合效果，单股不可靠**：Greenblatt 的研究显示神奇公式在组合（20-30 支）持有 1 年的情景下有统计显著性，但单支股票可能长期"被低估"而不涨。
- **A 股有效性存疑**：机构投资者比例、信息透明度、政策风险均与美股不同，历史效果需独立验证。

### 案例 A：看多——高盈利率 + 高 ROC

某工业零部件公司：
- EBIT = 10 亿，EV = 60 亿 → 盈利率 = 16.7%（高于要求的 10%）
- EBIT = 10 亿，投资资本 = 30 亿 → ROC = 33%（超基准 25%）
- 双指标均优异，公允股价计算：公允 EV = 10/10% = 100 亿，公允股价高于当前

### 案例 B：看空——低 ROC 资本陷阱

某钢铁厂：盈利率看似 12%（高），但投资资本 500 亿，EBIT 仅 60 亿，ROC = 12%（低于 25% 基准）。神奇公式对此公司排名靠后——其高盈利率来自市场定价偏低，但低 ROC 表明企业本质上是低质量的资本消耗型业务。

## 17. PE Relative Valuation（PE 历史分位）

### 适用场景

适用于**有足够历史 P/E 数据（≥ 5 年）的成熟盈利企业**，通过与自身历史估值中枢比较来判断高低。是券商研报中最常用的相对估值框架之一。

### 方法描述

以历史 P/E 均值（加权可选：70% 历史均值 + 30% 可比公司均值）作为基准，计算当前 P/E 位于历史分位数的哪个位置，并推导出公允股价。

### 计算公式

$$P_{\text{fair}} = EPS \times P/E_{\text{历史均值}}$$

若有可比公司数据：

$$P_{\text{fair}} = EPS \times (0.7 \times P/E_{\text{历史均值}} + 0.3 \times P/E_{\text{可比均值}})$$

**历史分位（百分位数）**：

$$\text{Percentile} = \frac{P/E_{\text{current}} - P/E_{\text{历史最低}}}{P/E_{\text{历史最高}} - P/E_{\text{历史最低}}} \times 100\%$$

**评估区间**：

| 分位数 | 评估 |
|--------|------|
| < 25th | 低估（历史底部四分位） |
| 25–40th | 轻微低估 |
| 40–60th | 合理区间 |
| 60–75th | 轻微高估 |
| > 75th | 高估（历史顶部四分位） |

### 配置参数与默认值

| 参数 | 默认值 | 说明 |
|------|-------|------|
| `historical_years` | 5 | 历史数据年数 |
| `fair_multiple_range` | ±15% | 与历史均值偏差在此区间视为"合理" |

### 方法局限性

- **均值回归假设可能错误**：行业结构性变化可导致 P/E 中枢永久抬升（如互联网平台化）或下移（如传统媒体萎缩），历史均值失去参考价值。
- **EPS 的周期性**：周期顶峰高 EPS 使当期 P/E 看起来低，但这是"假低估"。应使用正常化 EPS。
- **数据质量依赖**：历史 P/E 序列的准确性决定分析价值，低频数据（如仅有年度数据）会损失精度。
- **无法捕捉质量变化**：公司护城河增强（或削弱）后，历史 P/E 不能反映新的合理中枢。

### 案例 A：看多——万科 A（000002，假设）

- 当前 P/E = 8x，历史 5 年均值 P/E = 12x，历史区间 6x-18x
- 历史分位 = (8-6)/(18-6) = 16.7%（底部四分位以内）
- 公允价格 = EPS × 12 = 2.0 × 12 = 24 元
- 若当前股价 16 元，折价 33%，给出低估信号

但需警惕：房地产行业进入结构性下行周期，历史 P/E 均值可能无法代表未来合理估值。

### 案例 B：看空——历史分位高估

某白酒股：当前 P/E = 45x，历史 5 年均值 = 28x，历史最高 = 50x
历史分位 = (45-10)/(50-10) = 87.5%（历史顶部）
公允价格 = EPS × 28 = 大幅低于当前股价，高估信号明确。

## 18. PB Relative Valuation（PB 历史分位）

### 适用场景

适用于**银行、重资产行业、以资产价值为核心的企业**，通过 P/B 历史分位评估当前估值高低。逻辑同 PE 历史分位，但关注账面价值而非盈利。

### 方法描述

以历史 P/B 均值为基准，可叠加可比公司数据。P/B < 1 时触发特别提示（交易于账面价值以下）。

### 计算公式

$$P_{\text{fair}} = BVPS \times P/B_{\text{历史均值}}$$

**评估区间**（同 PE 历史分位，以历史分位数为准）

### 配置参数与默认值

| 参数 | 默认值 | 说明 |
|------|-------|------|
| `historical_years` | 5 | 历史数据年数 |

### 方法局限性

- 同 PE 历史分位，额外注意：
  - 账面价值的会计处理（重估、减值）可能使历史可比性降低
  - 金融危机等极端事件会使历史 P/B 区间出现偏低的离群点，拉低均值
  - P/B < 1 不必然是好事：也可能反映真实的资产减值预期

### 案例 A：看多——招商银行（600036）

- 当前 P/B = 0.85x，历史 5 年均值 = 1.4x，历史区间 0.7x-2.2x
- 历史分位 = (0.85-0.7)/(2.2-0.7) = 10%（历史极低分位）
- 公允价格 = BVPS × 1.4 = 38.5 × 1.4 ≈ 53.9 元（较当前有显著折价）

若基本面未恶化，历史低分位提供较强的均值回归逻辑。

### 案例 B：看空/局限——某已转型行业的公司

传统媒体公司：历史 P/B 均值 1.5x（鼎盛期），当前 P/B = 0.5x，历史分位极低。但业务已从纸媒转型数字化，资产内容库价值难以评估，历史账面价值中枢对当前无参考意义——这是 PB 历史分位的典型失效场景。

## 19. Altman Z-Score（破产预测）

### 适用场景

适用于**非金融上市公司的破产风险筛查**，常作为价值陷阱检测的第一道关卡。Z-Score 低的股票即使估值便宜，也可能面临偿债危机。

### 方法描述

Altman（1968）通过区分破产与非破产企业的财务比率，用判别分析构建出 5 变量综合模型。Z-Score 综合衡量流动性、盈利能力、杠杆结构和资产利用效率。

### 计算公式

$$Z = 1.2X_1 + 1.4X_2 + 3.3X_3 + 0.6X_4 + 1.0X_5$$

| 变量 | 定义 | 权重 | 经济含义 |
|------|------|------|---------|
| $X_1$ | 营运资本 / 总资产 | 1.2 | 短期流动性 |
| $X_2$ | 留存收益 / 总资产 | 1.4 | 历史积累盈利能力 |
| $X_3$ | EBIT / 总资产 | 3.3 | 当期资产盈利效率（权重最高） |
| $X_4$ | 市值 / 总负债 | 0.6 | 市场对资产负债结构的评价 |
| $X_5$ | 营业收入 / 总资产 | 1.0 | 资产周转效率 |

**判断区间**：

| Z-Score | 区域 | 风险级别 |
|---------|------|---------|
| > 2.99 | 安全区 | 低风险 |
| 1.81–2.99 | 灰色区 | 中等风险，需关注 |
| < 1.81 | 困境区 | 高风险，破产概率显著上升 |
| < 1.0 | 极度危险 | 需立即深度尽调或回避 |

### 配置参数与默认值

| 参数 | 默认值 | 说明 |
|------|-------|------|
| `zone_safe` | 2.99 | 安全区下限 |
| `zone_distress` | 1.81 | 困境区上限 |

### 方法局限性

- **不适用金融股**：银行高杠杆属于业务特性，Z-Score 会将所有银行都判为高风险。
- **制造业偏向**：Altman 基于 20 世纪 60 年代的制造业数据构建，对资产轻的服务业/互联网公司适用性有限（有改进版本的 Z''Score 用于非制造业）。
- **静态快照**：仅基于单期财报，不考虑现金流趋势；一个季度数据改善可能掩盖长期恶化趋势。
- **市值受市场情绪影响**：X₄ 中的市值在市场下跌时会使 Z-Score 虚低（公司基本面未变但 Z-Score 下降）。

### 案例 A：安全——中国神华（601088）

**假设数据（2024 年报）**：
- 营运资本 / 总资产 X₁ = 0.12
- 留存收益 / 总资产 X₂ = 0.30
- EBIT / 总资产 X₃ = 0.16
- 市值 / 总负债 X₄ = 2.50
- 营收 / 总资产 X₅ = 0.55

```
Z = 1.2×0.12 + 1.4×0.30 + 3.3×0.16 + 0.6×2.50 + 1.0×0.55
  = 0.144 + 0.420 + 0.528 + 1.500 + 0.550
  = 3.14（安全区）
```

**解读**：Z > 2.99，煤炭能源龙头资产质量好、盈利能力强，破产风险极低。

### 案例 B：危险——某高负债周期股

某房地产企业（假设）：
- 营运资本为负 X₁ = -0.08（预售款压低流动比率）
- 留存收益极低 X₂ = 0.02（高分红后留存）
- EBIT 大幅下滑 X₃ = 0.02
- 市值暴跌后 X₄ = 0.35（市值远低于负债）
- 资产周转低 X₅ = 0.20

```
Z = 1.2×(-0.08) + 1.4×0.02 + 3.3×0.02 + 0.6×0.35 + 1.0×0.20
  = -0.096 + 0.028 + 0.066 + 0.210 + 0.200
  = 0.41（极度危险区）
```

Z-Score 0.41 发出极端危险预警，结合行业背景，提示大幅回避或极高风险溢价要求。

## 20. Piotroski F-Score（财务质量）

### 适用场景

适用于**价值投资中的财务质量筛选**，由 Joseph Piotroski（2000）开发，专门用于在低 P/B 股票池中区分"真正便宜"与"价值陷阱"。F-Score 高的低 P/B 股票历史上表现显著优于 F-Score 低的。

### 方法描述

9 项二元（1/0）指标综合打分，涵盖盈利能力、资产负债改善、经营效率三个维度。需要同比数据（上一年度财务数据）才能评估趋势类指标。

### 计算公式（9 项指标）

**盈利能力（F1-F4，满分 4 分）**

| 指标 | 条件 | 得 1 分 |
|------|------|---------|
| F1 | ROA > 0 | 资产回报率为正 |
| F2 | 经营现金流 > 0 | 现金流质量 |
| F3 | ΔROA > 0 | ROA 同比改善 |
| F4 | 经营现金流 > 净利润 | OCF > NI（应计质量高） |

**杠杆与流动性（F5-F7，满分 3 分）**

| 指标 | 条件 | 得 1 分 |
|------|------|---------|
| F5 | 负债率下降 | 去杠杆 |
| F6 | 流动比率提升 | 流动性改善 |
| F7 | 股本未增加 | 无稀释性融资 |

**经营效率（F8-F9，满分 2 分）**

| 指标 | 条件 | 得 1 分 |
|------|------|---------|
| F8 | 毛利率改善 | 定价能力/成本控制 |
| F9 | 资产周转率提升 | 资产利用效率提升 |

**评分解读**：

| F-Score | 评级 | 建议 |
|---------|------|------|
| 8–9 | 强 | 质量优秀，低 P/B 则买入信号强 |
| 6–7 | 好 | 财务健康 |
| 4–5 | 一般 | 有担忧，谨慎 |
| ≤ 3 | 弱 | 警惕价值陷阱 |

### 配置参数与默认值

F-Score 的趋势类指标（F3/F5/F6/F7/F8/F9）需要上年度数据，通过构造函数传入：

| 参数 | 说明 |
|------|------|
| `prior_roa` | 上年 ROA |
| `prior_debt_ratio` | 上年负债率 |
| `prior_current_ratio` | 上年流动比率 |
| `prior_shares_outstanding` | 上年股本（判断稀释） |
| `prior_gross_margin` | 上年毛利率 |
| `prior_asset_turnover` | 上年资产周转率 |

若上年数据缺失，对应指标被标记为"跳过"，最终得分与可比最大分相对比。

### 方法局限性

- **需要同比数据**：6 个趋势类指标都需要上年度数据，数据完整性决定评分有效性。
- **非财务因素完全忽略**：护城河、管理层质量、行业竞争格局均未纳入。
- **不适用金融股**：银行的资本比率、拨备覆盖率才是核心，F-Score 的 9 个维度对银行无意义。
- **Binary 评分过于简化**：每项指标只有 0/1，无法区分"轻微改善"与"大幅改善"。

### 案例 A：看多——高 F-Score 低 P/B 股

某制造业公司：P/B = 0.7x（价值区间），F-Score = 8/9（各维度均优秀）：
- F1: ROA = 9%（正）✓
- F2: OCF > 0 ✓
- F3: ROA 从 7% 升至 9%（改善）✓
- F4: OCF > 净利润（高质量）✓
- F5: 负债率从 42% 降至 38%（去杠杆）✓
- F6: 流动比率从 1.4 升至 1.6 ✓
- F7: 股本无增加 ✓
- F8: 毛利率从 28% 升至 31%（改善）✓
- F9: 资产周转率略降（失分）✗

F-Score = 8，配合低 P/B，是价值投资的理想目标。

### 案例 B：价值陷阱——低 P/B 低 F-Score

某传统行业公司：P/B = 0.5x，看似极度低估，但 F-Score = 2/9：
- ROA 为负（F1 失分），OCF 为负（F2 失分），负债率上升（F5 失分）等
- 这正是价值陷阱的特征：估值低是有原因的，财务质量持续恶化。

## 21. Beneish M-Score（盈余操纵检测）

### 适用场景

适用于**盈余质量审查**，尤其对于高速增长、分析师预期高、管理层薪酬与盈利高度挂钩的公司，在投资前进行财务舞弊风险筛查。

### 方法描述

Beneish（1999）通过研究历史财务舞弊案例，构建了 8 变量概率模型，计算每家公司进行盈余操纵的概率。模型并非宣称公司一定造假，而是提示需要进一步调查的高风险信号。

### 计算公式

$$M = -4.84 + 0.92 \cdot DSRI + 0.528 \cdot GMI + 0.404 \cdot AQI + 0.892 \cdot SGI + 0.115 \cdot DEPI - 0.172 \cdot SGAI + 4.679 \cdot TATA - 0.327 \cdot LVGI$$

**8 变量定义**（均需同比数据）：

| 变量 | 全称 | 定义 | 高值含义（操纵信号） |
|------|------|------|---------------------|
| DSRI | 应收账款天数指数 | (应收/营收)ₜ / (应收/营收)ₜ₋₁ | 应收账款膨胀，虚增收入 |
| GMI | 毛利率指数 | 毛利率ₜ₋₁ / 毛利率ₜ | 毛利率恶化，压力下操纵 |
| AQI | 资产质量指数 | (1-液态资产/总资产)ₜ / (1-液态资产/总资产)ₜ₋₁ | 非流动资产异常增加 |
| SGI | 收入增长指数 | 营收ₜ / 营收ₜ₋₁ | 高增速带来业绩压力 |
| DEPI | 折旧指数 | 折旧率ₜ₋₁ / 折旧率ₜ | 延长折旧年限，虚增利润 |
| SGAI | 费用指数 | (SG&A/营收)ₜ / (SG&A/营收)ₜ₋₁ | 费用率上升，效率下降 |
| TATA | 应计总资产比率 | (经营利润 - 经营现金流) / 总资产 | 利润与现金流脱节 |
| LVGI | 杠杆指数 | 负债率ₜ / 负债率ₜ₋₁ | 债务压力增加操纵动机 |

**判断阈值**：

| M-Score | 解读 |
|---------|------|
| < -2.22 | 非操纵者（安全） |
| -2.22 至 -1.78 | 警戒区，建议进一步调查 |
| > -1.78 | 高概率操纵者（慎重） |
| > -2.22 | 广义上疑似操纵（常用宽松阈值） |

### 配置参数与默认值

M-Score 所有 8 个变量均需要**本年度与上年度**的财务数据，是 valueinvest 库中数据要求最严格的模型之一。

### 方法局限性

- **历史率约 50-70% 的准确率**：原始研究在样本内有较好表现，但在未见样本上存在较高误报率，不能直接据此排除公司。
- **需要两年数据**：若只有当期数据，所有趋势类变量无法计算。
- **文化与会计准则差异**：Beneish 模型基于美国 GAAP 样本，中国会计准则下部分变量定义不完全一致。
- **合理的高分不等于舞弊**：高速成长的真实优质企业（如国际化扩张中的消费品公司）DSRI、SGI 指数可能同时偏高，触发警告但并非造假。

### 案例 A：低风险——贵州茅台（600519）

茅台特点：
- DSRI ≈ 1（预收款模式，应收账款极低，增长缓慢）
- GMI ≈ 1（毛利率稳定在 91-93%）
- TATA 极低（经营现金流显著高于净利润，应计比率极低）
- M-Score 通常 < -3.0（深度安全区）

**结论**：预收款商业模式天然对 Beneish 模型友好，当期收入确认审慎，盈余操纵风险极低。

### 案例 B：高风险预警——某高速成长科技公司（假设）

- DSRI = 1.45（应收账款增速远超收入增速）
- SGI = 1.80（收入高速增长，管理层压力大）
- TATA = 0.08（应计利润占总资产 8%，远高于正常 1-2%）

```
M = -4.84 + 0.92×1.45 + 0.528×1.10 + 0.404×1.20 + 0.892×1.80 
    + 0.115×1.05 - 0.172×1.10 + 4.679×0.08 - 0.327×1.10
  ≈ -4.84 + 1.334 + 0.581 + 0.485 + 1.606 + 0.121 - 0.189 + 0.374 - 0.360
  ≈ -0.89（高于 -2.22，疑似操纵）
```

应进一步核查：应收账款明细、存货是否异常增长、关联交易是否合理。

## 22. Value Trap Detection（价值陷阱检测）

### 适用场景

**任何表面低估的股票投资前的综合尽调**，尤其适用于 P/B < 1 或 P/E 极低的情景。价值陷阱（Value Trap）指看似便宜但实际上将持续低迷甚至亏损的投资。

### 方法描述

从五个维度综合评估企业是否存在价值陷阱风险，每个维度给出风险评分。五大维度来自 `value_trap.py` 的实现：

| 维度 | 核心问题 | 关键指标 |
|------|---------|---------|
| 财务健康 | 是否有偿债危机？ | Altman Z-Score、流动比率、利息覆盖率、负债率 |
| 业务恶化 | 竞争力是否持续下滑？ | 收入增速、毛利率趋势、市场份额变化 |
| 护城河侵蚀 | 护城河是否在被破坏？ | ROE 趋势、ROIC 趋势、定价权变化 |
| AI/技术脆弱性 | 是否面临技术颠覆？ | 行业数字化程度、研发投入比例、商业模式可替代性 |
| 股息信号 | 分红是否可持续？ | 派息率、自由现金流覆盖率、股息削减历史 |

### 配置参数与默认值

价值陷阱检测为定性+定量综合模型，使用 5 维度加权评分。每个维度独立评估风险等级（低/中/高），综合给出"高风险/中风险/低风险"结论。

### 方法局限性

- **定性判断占比较大**：护城河侵蚀、AI 脆弱性部分依赖分析师主观判断，结果可能因人而异。
- **无法量化所有风险**：管理层腐败、政策风险、黑天鹅事件均无法纳入模型。
- **实时性要求高**：业务恶化信号需要结合最新季报甚至渠道调研，历史财报数据存在滞后性。

### 案例 A：低价值陷阱风险——长江电力（600900）

- 财务健康：Z-Score > 4，流动比率良好 → 低风险
- 业务恶化：水电发电量随来水量小幅波动，但长期用电需求增长 → 低风险
- 护城河：水电站具有天然垄断特性，许可证壁垒极高 → 低风险
- AI 脆弱性：能源生产非 AI 可颠覆的核心业务 → 低风险
- 股息：FCF 充足，派息率 60-70%，历史无削减 → 低风险

**综合结论**：价值陷阱风险极低，低估即为真实低估。

### 案例 B：高价值陷阱风险——某传统零售商

- 财务健康：负债率高，Z-Score = 1.5 → 中等风险
- 业务恶化：营收同比 -12%，电商冲击持续 → 高风险
- 护城河：门店优势被拼多多/京东瓦解 → 高风险
- AI 脆弱性：供应链和推荐系统被大型平台降维打击 → 高风险
- 股息：FCF 为负，股息靠借债维持 → 高风险

**综合结论**：价值陷阱高风险，即使 P/B = 0.4x 也应回避。

## 23. SBC Analysis（股权激励稀释分析）

### 适用场景

**科技公司、高成长型企业**，尤其是大量使用股权激励（SBC：Stock-Based Compensation）吸引人才的公司。SBC 通过发行新股向员工支付薪酬，稀释现有股东权益，需要从净利润中还原这部分"被隐藏的成本"。

### 方法描述

分析股权激励的规模及其对每股内在价值的稀释程度，评估管理层是否在"用股东的钱发员工薪酬"。通过 SBC 占净利润比例和股本增速来判断稀释压力。

### 关键指标

| 指标 | 计算 | 含义 |
|------|------|------|
| SBC 占净利润比例 | SBC / Net Income | 盈利中有多少比例是"非现金激励成本" |
| SBC 占营收比例 | SBC / Revenue | 收入规模下的薪酬成本负担 |
| 股本年化稀释率 | (当期股数 - 上期股数) / 上期股数 | 每年稀释百分比 |
| 调整后 EPS | (净利润 - SBC) / 股数 | 还原 SBC 后的真实每股盈利 |

**稀释性评级**：

| SBC/净利润 | 年稀释率 | 评级 |
|-----------|---------|------|
| < 5% | < 1% | 可忽略 |
| 5-15% | 1-2% | 轻度稀释 |
| 15-30% | 2-4% | 中度稀释，需关注 |
| 30-50% | 4-7% | 严重稀释 |
| > 50% | > 7% | 极度稀释，重大风险 |

### 配置参数与默认值

SBC 分析使用以下来源的数据：
- `stock_based_compensation`：SBC 金额（来自现金流量表附注）
- `net_income`：净利润
- `shares_outstanding`：当期股本
- `prior_shares_outstanding`：上期股本（可选，用于计算稀释率）

### 方法局限性

- **A 股 SBC 披露不够规范**：部分 A 股公司在现金流量表中未单独列示 SBC，数据获取困难。
- **期权 vs 限制性股票**：不同形式的 SBC 稀释节奏不同（期权行权时稀释，限制性股票解禁时稀释），汇总数字可能掩盖时机差异。
- **增长阶段需区别对待**：高速成长期（员工数倍速增加）的 SBC 比例天然偏高，不能直接与成熟期公司类比。
- **回购可对冲稀释**：部分公司通过大量回购抵消 SBC 带来的稀释（如美股科技公司），净稀释率才是真正重要的指标。

### 案例 A：低稀释——贵州茅台（600519）

茅台 SBC 极低（公司文化偏向现金分红而非股权激励），SBC/净利润 < 1%，年稀释率近于零。不存在 SBC 稀释风险，报告盈利即为真实盈利。

### 案例 B：高稀释警告——某 A 股互联网公司（假设）

- 净利润 = 30 亿元
- SBC = 15 亿元（主要为核心技术人才期权）
- SBC / 净利润 = 50%
- 过去 3 年股本从 50 亿股增加至 55 亿股，年均稀释 3.3%

**调整后真实 EPS**：
```
调整前 EPS = 30 / 55 = 0.545 元
调整后 EPS = (30 - 15) / 55 = 0.273 元
实际 P/E（基于调整 EPS）= 股价 / 0.273（是名义 P/E 的 2 倍）
```

如果投资者仅看名义 P/E = 18x，忽略 SBC，实际承受的调整后 P/E 约 36x。高稀释叠加高估值，需谨慎对待。
