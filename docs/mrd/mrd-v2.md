## 1. 概述

### 1.1 要解决什么问题（MRD-1.1）`[v1 占位 → 建议正文]`

一期所有规则（-15% 止损、单票上限、加仓限制、再平衡阈值）都是**经验命题**：它们声称改变交易结果，就必须有证据。飞书 r482 §回测模块·一 给出的可复算证据是——同一批交易，-15% 止损净亏 **5.2 万元**，-25% 止损反而净赚 **2.9 万元**；「跌破 MA60 卖出」在 81 笔里触发 80 次、净亏 **29.7 万元**。阈值动一格结论就反向，说明当前真正缺的不是「更聪明的规则」，而是「能证伪规则的台子」。

不做会怎样：一期 P0 的「持仓体检 + 止损门禁」会把**未经验证**的阈值制度化；飞书 §七「一期完成的定义」里「至少一个买点条件通过样本外验证，或明确得出『无信号』」不可能达成；后续所有策略讨论没有共同事实基础。该缺口对应 2020–2026 复盘暴露的第 6 个问题 P6「没有验证能力」。`[待确认]`

### 1.2 现状与瓶颈（MRD-1.2）`[v1 占位 → 建议正文]`

- **能力侧**：`openspec/specs/` 现行 69 个 capability 无一提供「可复现的历史验证」；`trade-review-attribution` 只能对**已发生**成交做 FIFO 复盘，回答不了「换一条规则会怎样」；`portfolio-analyzer` 只算集中度。`[已实现：仓库现状]`
- **数据侧（三处口径缺口）**：三个数据源适配器一律取**前复权**（`src/data_provider/baostock/fetcher.py:363`、`src/data_provider/tushare/fetcher.py:295`、`src/data_provider/akshare/fetcher.py:109`），前复权会随新分红改写历史价、制造假信号；本地 `kline` 表只有 OHLCV 五列，**无 `amount`/日均成交额**（`src/dao/models.py:134`），做不了分层滑点与流动性上限；财务数据只有报告期、无表级 `ann_date`（`src/dao/models.py:31`），无法做「按公告日对齐」。`[已实现：仓库现状]`
- **制度侧**：无预注册、无实验台账、无 K 计数 → 无法区分「规则有效」与「参数恰好」。`[待确认]`

一期 P0 的核心能力 = **一个历史验证台子**（数据对齐 + 撮合 + 指标 + 台账 + 门禁），不是策略结论。按 12 组语义（对应 `add-backtest-engine` 的 19 条 Requirement，编号 R1–R19 为该 change 内部编号，**不是 MRD 锚点**）：`[待确认]`

| --- | --- | --- |
| 1 | 实验先预注册再跑数，跑完只能新开实验 | R1 / R2 |
| 2 | 三段样本（2015–2020 / 2021–2023 / 2024–2026），样本外只烧一次 | R3 / R4 |
| 3 | 报告 K 并做 Bonferroni 或 Deflated Sharpe 校正 | R5 |

### 3.2 可信保证（MRD-3.2）`[v1 占位 → 建议正文]`

结论必须可复核，不接受「效果好」这类表述。四条硬要求：`[待确认]`

1. **可追溯**：任一实验可由一条命令导出「假设 / 参数 / 样本区间 / K / 结果 / 是否触达样本外 / 预注册 commit」；

4. **可阻塞**：校准未通过 → 拒绝输出任何研究结论（退出码非 0），且不得表述为「策略无效」。

## 4. 场景

### 4.1 核心场景（MRD-4.1）`[v1 占位 → 建议正文]`

- **S-a 导出一次实验的全部证据**：Owner 想复查某条规则试过多少次、K 是多少 → 一条命令导出 13 字段台账（含 `burnt`、`run_status`、`prereg_commit`），字段与预注册逐字一致。`[待确认]`
- **S-b 事件研究允许「无信号」**：某条件在全样本上**零触发** → 结论为 `INCONCLUSIVE`（`windows={}`、`n_events=0`、退出码 0），而不是报「数据缺口」；这与「有信号」同等计入台账与 K。`[已实现：TC-R17-04 锁定]`
- **S-c 门禁跳级被拒**：规则未过回测即申请影子运行 / 影子期不满 6 个月即申请实盘 → 拒绝并留痕（`GateSkipError` + REJECTED 执行行），状态不变。`[已实现]`
